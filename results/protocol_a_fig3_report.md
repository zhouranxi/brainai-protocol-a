## 结论

1. **GLUE 三标记在 224 模型上同样经受住 ID 受控 + 架构去混淆**：稳健标记 = `dimension_id`, `radius_id`, `utility_id`
2. **ID 准确率的符号跨数据集不稳定**：本数据残差化 r = +0.392 (ρ = +0.365)，但 80 模型数据为 −0.65 —— **符号在两份官方数据间翻转**，而 `dimension_id` 稳定在 +0.71~+0.93 → ID 准确率不可作跨数据集基线
3. **增量信息空间**：ID 跨度仅 1.92 个百分点时，OOD 跨度仍保留 91.8%
4. **GLUE 三标记的结论在两份官方数据与一份自建数据上三方一致**（`dimension_id` / `utility_id` 方向与量级均一致）；但 `radius_id` 与 `acc_test` 的符号在两份数据间不稳定，→ 这两个量**不能作为稳定预测器**，已在表 T2 标注为不稳健。
