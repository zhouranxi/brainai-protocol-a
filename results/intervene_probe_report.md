# 任务四效应量探测报告：D_eff 的推理期干预 → OOD 因果效应

- 日期：2026-11-04（00:00–00:30，学校 4×3090 服务器，GPU 1/2/3 分片）
- 脚本：`code/intervene_effect_probe.py`；原始数据：`runs/probe/g{1,2,3}.json`（96 行）
- 设计对应：ADR-0016 候选 B 前置闸门（"先用 2–3 天做效应量探测，再决定是否全面展开"）

## 一、设计

8 个固定 ID 准确率区间的 resnet18（id_acc 0.851–0.884，48 模型池按分位数挑选）。
每个模型抽 penultimate 特征后，在 **ID 特征上拟合**类无关干预算子（ID-only，
符合"预后性"设定），以 12 个条件作用于全部特征：

| 族 | 算子 | 预期 D_eff 响应 |
|---|---|---|
| flatten(α=0.5/1/2/4) | X + α·σ_w·ε，ε~N(0,I) 各向同性 | ↑（流形谱平坦化） |
| sharpen(k=0.75/0.5/0.25/0.1) | 只保留类内协方差前 k 比例主轴 | ↓ |
| placebo(α=1/2/4) | 范数匹配的**单固定方向**噪声 | 不动（关键对照） |
| base | 无 | — |

每个条件测：扰动后 ID 特征上的 GLUE 三指标（操纵检查）、ID acc（原 fc 头）、
CIFAR-100 linear probe（探针在扰动特征上重训）、CIFAR-10C acc。

## 二、结果

### 8 模型均值（全表见 runs/probe/）

| 条件 | D_eff | id_acc | c100 probe | c10c acc |
|---|---|---|---|---|
| base | 1.30 | 0.8712 | 0.1890 | 0.6240 |
| flatten 0.5 | 2.37 | 0.8711 | 0.1324 | 0.6232 |
| flatten 1.0 | 4.11 | 0.8699 | 0.1210 | 0.6221 |
| flatten 2.0 | 7.72 | 0.8669 | 0.1018 | 0.6179 |
| flatten 4.0 | 12.96 | 0.8481 | 0.0830 | 0.5991 |
| sharpen 0.1 | 1.14 | 0.8712 | 0.1720 | 0.6241 |
| placebo 4.0 | 1.31 | 0.8711 | 0.1890 | 0.6239 |

### 三道检查

1. **操纵检查 ✅**：flatten 强度与 D_eff 的逐模型 Pearson r ≥ 0.992（8/8），
   D_eff 从 ~1.3 单调推到 ~13（10 倍）。
2. **安慰剂检查 ✅（干净得近乎完美）**：placebo 4.0（与 flatten 1.0 同等噪声功率）
   对 D_eff/ID/c100/c10c 的影响全部 ≤ 0.03 / 0.0008 / 0.0003 / 0.0001。
   → 排除"噪声功率本身"的解释：起作用的是**方差被摊到多个方向**（这正是 D_eff 度量的东西）。
3. **ID 功能保持 ✅**：α≤2.0 时 ID acc 变化 < 0.5pp，而 c100 已相对下降 46%。

### 核心发现：因果效应与观察相关**反号**

- 观察性（48 模型，ID 受控 + 架构残差化）：D_eff ↔ c100 probe **r ≈ +0.92**
- 干预性（本实验，ID 受控窗口内）：D_eff ↑ 10 倍 ⇒ c100 **单调下降 −56%（相对）**
  - 逐模型 flatten 斜率 d(c100)/d(D_eff)：**8/8 全负**，中位 −0.0047
- c10c 同向：0.6240 → 0.5991

## 三、判读

1. **观察相关不是因果收益**。"D_eff 高的模型迁移好"不能读成"提高 D_eff 会改善迁移"。
   D_eff 是配方驱动的**伴随标记**（与测量论文"指标测的是配方"结论互恰），
   真正携带迁移信息的是与高 D_eff 共变的其它训练产物。
2. **效应量本身很大且干净** → 按 ADR-0003 闸门，**GO**：管线跑通、操纵/安慰剂/ID 保持
   三道检查全过、效应单调且 8/8 模型同号。值得全面展开。
3. **但因果声明必须限定算子**：flatten 通过加各向异性噪声操纵流形几何，
   它证明的是"该算子族的因果效应为负"，不是"D_eff 本身无因果作用"。
   全面展开阶段需要补"不加噪声的升维算子"（如类流形旋转/子空间缩放/流形插值）
   才能分离"几何"与"噪声"两条路径。

## 四、第二步：无噪声谱重着色（2026-11-04 上午，`code/intervene_recolor.py`）

补 2×2 表的最后一格——**零噪声的 D_eff 操纵**。算子 `recolor(γ)`：
类内谱重着色 `x' = μ + V·diag(λ^((γ-1)/2))·Vᵀ(x−μ)`，确定性、零噪声、γ=1 恒等；
γ=0 全白化（类内各方向等方差）。对照 `tot_recolor`：同形式但作用于总协方差谱。
新增 10-way ID probe 通道（区分"信息被破坏"vs"头部不兼容"）。

### 2×2 因果分离表（8 模型均值，Δ 相对各自 base）

| 机制 | D_eff 变化 | Δc100 | 一致性 |
|---|---|---|---|
| **噪声注入** D↑（flatten α=4） | +11.7 | **−0.106** | 8/8 模型为负 |
| **零噪声白化** D↑（recolor γ=0） | +4.5（低 lr 模型 +9.8） | **+0.020** | 斜率 6/7 为正 |
| **零噪声投影** D↓（sharpen k=0.1，3 个有效模型） | −0.45 | **−0.045** | 3/3 同向降 |
| 安慰剂（placebo α=4） | +0.01 | −0.0001（max \|Δ\|=0.0003） | — |

关键细节：

- **白化端点 ID probe 完全保持**（如 0.8712→0.8741，甚至微升）——信息没被破坏。
  同样把 D_eff 推高 ~10，白化让 c100 不降反微升（低 lr 模型 +0.002～+0.056），
  噪声注入让 c100 崩掉 −0.05～−0.18。**同样的 D_eff 变化，相反的 OOD 后果。**
- recolor 逐模型斜率中位 +0.008/单位 D，仅约为观察斜率（≈+0.13/单位 D）的 **6%**。
- tot_recolor 对照中位 +0.0087，与类内谱算子几乎相同——效应不特异于类内谱，
  进一步支持"算子的伤害来自噪声功率分布而非流形几何本身"。
- sharpen 方向（D↓ ⇒ c100↓，幅度 ≈ 观察斜率量级）与观察相关同向，
  但 n=3（只有低 lr 模型的 D_eff 有下探空间），且投影丢方差=丢信息，
  不能与白化方向等权重解读。

### 结论（两步合并）

1. **观察相关的主体是配方混杂，但不是全部。** 几何通路的因果效应存在
   （D↓伤、白化式 D↑微益，方向都与观察一致），但幅度比观察斜率小一个数量级。
   跨模型间 D_eff 的差异（D 0.9→2.1，c100 0.12→0.30）绝大部分不能通过
   操纵单个模型的 D_eff 来复制。
2. **第一步的反号效应全部来自噪声注入，与几何无关。** "提高 D_eff 会伤害 OOD"
   是错误结论；"往表征里注各向异性噪声会伤害 OOD"才是对的。
3. **D_eff 是真实的描述统计量 + 弱因果通路 + 强配方标记**，三重身份。
   这为干预论文提供了精确的定位：干预工具的价值不在"改进 D_eff"，
   而在分离这三重身份。

### 技术脚注（可复现的 QP 不收敛）

`resnet18_lr0.5_wd0.0001_s1` 的 `recolor=1.5` 条件使 cvxopt QP
（`glue_impl.py`，maxiters=1e6、abstol=1e-10）不收敛，三次独立重跑均在同一
条件挂起（100% 单核、GPU 0%）。该模型为 floor 模型（base D≈1.04，白化空间小），
最终接受 7/8 模型全条件 + 该模型 2 点。后续全面展开时应给 glue_analysis
加 wall-clock 看门狗。
