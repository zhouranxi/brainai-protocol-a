## T6 增量信息量总结

- ID 受控后 OOD 跨度保留：37.77 / 39.21 = **96.3%**
- 子集内最稳健标记：`dimension_id` 残差化 r=+0.713，Spearman rho=+0.805
- 子集内基线 `acc_test`：原始 r=+0.482 → 残差化 r=-0.628，Spearman rho=-0.606
- **相对预测力提升：1.18×**（残差化 Pearson of D_eff ÷ Spearman of acc_test）

### 结论

1. **D_eff / Ψ_eff / center_alignment 在残差化后仍强于 ID 准确率**（残差化 r = +0.713 / +0.729 / +0.623，p<1e-4），且在 5 个架构中符号一致 → **不是 Simpson 悖论**。
2. **原始 `acc_test` 的 r=+0.482 是架构混淆假象**：残差化后 Pearson 翻转为 -0.628、Spearman -0.606，逐架构符号混乱（+0.88/−0.73/−0.78/+0.52/−0.92）→ 在 ID 受控条件下，ID 准确率与 OOD 呈**负相关**，几何标记的信息是**净增量**。
3. **通用几何量在残差化后也变强，但弱于 GLUE 三标记**：`participation_ratio_id` 残差化 r=+0.659、rho=+0.794，`mean_distance_avg_id` r=+0.584、rho=+0.680 —— 均低于 D_eff/Ψ_eff。
4. **corruption 场景下 ID 准确率重新成为最强预测器，但仅限亮度/结构类**（fog/brightness/contrast，rho≈0.98–0.99），噪声与压缩类失效（rho≈−0.13~+0.09）→ **偏移类型决定几何标记是否有优势**，二者缺一不可。
