# C2 实验报告：表征几何指标能否预测模型质量

- 数据集：CIFAR-10（50000 train / 10000 test）
- 架构：resnet18（torchvision，从头训练）
- 模型组数：42（3 种子 × 14 配方）
- 非平凡指标（不使用标签）：effective_dim, local_smoothness, criticality_proxy, spectral_entropy
- 平凡指标（使用测试标签，与 test_acc 同源）：silhouette_gap, linear_probe_acc

## M0 结论

### **NO-GO**

**无指标通过 M0 判据。**

判据（ADR-0003 + ADR-0002）：

1. 属非平凡指标（不使用测试标签）
2. |Pearson r| ≥ 0.7 且 p < 0.05
3. |Spearman ρ| < 1.0（不能只是性能的单调重标度）
4. 全部种子下结论一致
