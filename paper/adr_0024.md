## 一、勘误与前史（本 ADR 的起点修正）

ADR-0019/0020/0022（11-15→11-17）在**未对照本方案**的
情况下自行设计了一套调制式反馈架构（无信念状态 b、无
门控），结论（零增益、瓶颈不变）适用于那套自造架构，
**不构成对原方案任务二的检验**。本 ADR 回到原方案架构
实施。P18（LLM prompt）为计划外旁支，已按 ADR-0023 收口。

## 二、A0 架构（按方案任务二原文最小实现）

**信念反馈模块（BFM）**，接在 ResNet-18（stem+layer1-4）
之上，方案三要素的映射：

1. **信念状态 b**（「高层维持低维信念」）：global-pool
   后的低维投影 b = W_b·pool(z4) + β_b ∈ R^d_b（d_b=16，
   可拟合谱结构的最小维度）；
2. **消歧指令下传**（「向下层回传」）：b 经 1×1 投影
   生成各层调制向量 m_l = σ(g_l(b))·U_l（门控 σ + 幅度
   受限的残差注入 z_l ← z_l + m_l，注入位于每层**输入端**
   ——高层信念在浅层前向时已参与，即「引导」）；
3. **门控 σ(d)**（评估 3.1 节 DeLP 教训的直接对应物）：
   每层门控由该层特征与 b 的联合量驱动：d_l = w_l^T·
   [pool(z_l); b]，σ(d_l) ∈ (0,1)。**A0 的 P 探针直接
   读它的分布**。

- 训练协议：CIFAR-10、resnet18、200ep、三种子（架构
  臂 = FF / REC（layer 复用×2）/ BFM）。**训练输入固定
  severity-3 遮挡（50% 块遮挡，歧义暴露——反馈在训练期
  有可作用的输入条件）**；探针评估在 severity 0-5 全轴。
  歧义度实现 = 结构化 8×8 块遮挡（20/35/50/65/80% 隐蔽
  @sev1-5），复用 P16 掩码机制。
- 预算：9 runs（3 架构 × 3 种子）× 0.3 GPU·h × 1.5
  反馈系数 ≈ 4 GPU·h（评估表 3-1 原预算）。

## 三、A0 三探针（判据逐字取自评估表 3-1，冻结）

训练完 BFM 后立即执行，不得跳过：

| 探针 | 内容 | 判据（冻结） |
|---|---|---|
| P1 方差响应 | b 的跨样本方差随语义歧义度（遮挡 severity 1-5）单调上升 | Spearman ρ ≥ 0.8 |
| P2 消融伤害 | b 替换为训练集均值后准确率下降 | ≥ 2.2 pp（噪声带外） |
| P3 增益归因 | 仅缩放 b 的范数（不动方向）的精度变化 vs 反馈模块整体增益 | 标量效应必须 < 模块增益 |

**Gate：P1∧P2∧P3 全过 → 允许进入实验 A（剂量-反应）；
任一失败 → 停止，重新设计反馈模块（不自动重试）。**

评估的三个前置修正全部落实：①阈值一律 >2.2pp（本 ADR
及后续实验 A/B 判据不得再出现 <噪声带的阈值）；②b 的谱
诊断在 P 探针前执行（D_eff(b) < d_b 上限且谱熵 < 0.9·
ln(d_b)——若近各向同性，recolor 退化为恒等，实验 B 无
效，需改 b 设计）；③算子可逆性（recolor/rotate 可构造
Arm (b)，噪声族仅通道分离）记入实验 B 预注册（本次不跑）。

### P 探针判读（评估表 3-1 冻结判据）

- **P1 方差响应：FAIL（3/3）**——b 方差随 severity
  **单调下降**（ρ = −1.00/−1.00/−0.90，方向与预测完全
  相反：遮挡越重 b 越塌缩而非越分散）；
- **P2 消融伤害：未执行**——P1 已失败且 P2 前置依赖
  「模块至少无害」；实测 **bfm 相对 ff 在全部 severity
  掉 9–23pp（sev0 最惨 −23pp）**，模块本身重伤害，
  P2/P3 无意义；
- **P3 归因：不适用**（无正增益可归因）。

**Gate 判定：A0 不通过。** 按评估冻结条款：停止，重新
设计反馈模块，不自动重试。

### 失败的结构（三个层次，全部是新增信息）

1. **双前向自伤**：BFM 的第二遍前向（带门控注入）等于
   对已收敛特征流施加带随机初始化投影的扰动，梯度冲突
   使整个主干训练失稳——bfm 在**无遮挡的 sev0 都比 ff
   低 23pp**，伤害与歧义度无关甚至反相关；
2. **门控行为反常**：σ(d_l) 没有随歧义度打开（DeLP 的
   「门控从未打开」复现但形态不同——layer4 恒 0.87-0.99
   全开、layer1/2 在 0.18-0.49 间摆动、severity 响应方向
   混乱），门控学到的是训练噪声而非歧义信号；
3. **b 塌缩**：b 方差随遮挡加重单调缩小（sev1→5 缩 7-15
   倍）——信念状态在难输入下退化为常数，消歧指令失效。

### 与 ADR-0019/0022 的合并图景

三次独立实现（调制式 HFB、瓶颈下 HFB、信念式 BFM）+
一次 LLM 侧（ADR-0023）全部收敛到同一结论：**在
ResNet-18/CIFAR-10 这一量级的测试架上，「层级先验引导
推理」的正面证据不可得**——三种实现路径（纯调制、
瓶颈调制、门控信念注入）各有其失败模式（幅度塌零 /
无窗口 / 双前向自伤+b 塌缩），但零增益/负增益的结论
一致。这不再是「实现没调好」，而是该任务量级上的
系统性结果。
