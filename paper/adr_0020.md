# ADR-0020：REC-OOD 效应的机制与边界——N4

- 决策人：Lance（用户）；执行：WorkBuddy（无涯智）

## 一、问题

同层横向自连接（REC：z ← z + σ(lat(z))·z，推理时贡献
为零）在 ID 无差的情况下使 c100 探针迁移 +4.0pp。三候选
机制：

- **M-平滑**：训练时的横向调制起「特征平均」作用——等价
  于对表征做平滑正则，改善探针可读性；
- **M-增广**：横向通路的随机性（初始化+梯度噪声）等价于
  隐式数据增广——测试时虽关掉，训练正则化收益留下；
- **M-集成**：横向自连接等效于同层多视角的轻量集成——
  探针读出时特征更稳定。

判别性预测（跑前写死）：

| 机制 | 训练后特征扰动敏感度↓ | dropout 等价正则替代应复现 | 特征稳定性↑ |
|---|---|---|---|
| M-平滑 | 是 | 否 | 是 |
| M-增广 | 否 | 是 | 否 |
| M-集成 | 否 | 否 | 是 |

## 二、N4 设计（跑前冻结）

### N4a（机制判别，12 run）

1. **P 臂（扰动敏感度，6 run）**：REC 与 FF 各 3 种子，
   训练后对 penultimate 特征注入高斯噪声 σ∈{0, 0.1, 0.3}
   （×单位方差归一），测 c100 探针随 σ 的衰减曲线。若 REC
   的衰减显著慢于 FF → 特征更稳健（M-平滑/M-集成预测）；
   若无差 → M-增广方向。
2. **D 臂（dropout 等价对照，6 run）**：FF + 特征层
   dropout p=0.1（训练时施加于 penultimate，等价正则替代）
   × 3 种子 vs FF 原配 3 种子（N1″ 复用）。若 FF+dropout
   复现 +4pp → M-增广（正则化通道）成立。

### N4b（边界，12 run）

REC/FF 各 3 新种子（6/7/8）× CIFAR-10-C 评估（19 种腐蚀
×5 强度，官方口径）：效应是否在分布外腐蚀上复现、哪些
腐蚀类型受益最大。6 run 训练 + 复用 N1″/N2b 的 12 个已有
checkpoint 一起评（零额外训练）。

### 判读（冻结）

- **J1（P 臂主判读）**：σ=0.3 时 REC 与 FF 的 c100 衰减差
  ≥ 2pp → 「特征稳健性」通道（M-平滑/M-集成族）；无差
  → M-增广方向（由 J2 裁决）。
- **J2（D 臂）**：FF+dropout(0.1) 的 c100 − FF ≥ +2pp
  → M-增广成立（正则化通道可复现效应）；否则 M-增广
  排除——若 J1 同时无差 → 三机制全否，挂 M-其他（描述
  横向通路的具体作用面）待 N5。
- **J3（N4b）**：REC−FF 的腐蚀 acc 差均值 ≥ +1.5pp 且
  ≥13/19 腐蚀同向正 → 效应泛化到真 OOD；否则效应是
  c100-探针特异（记录边界）。
- **J4（健康闸）**：全部新训 run id_test ≥ 0.90。
