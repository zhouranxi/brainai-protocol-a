# ADR-0020：REC-OOD 效应的机制与边界——N4

- 状态：已收口（三机制全否 + 腐蚀不泛化：REC-OOD 定性为 c100-probe-specific 可读性效应）
- 日期：2026-11-15 22:50 立项
- 前置：ADR-0019 N2b（REC-OOD +4.0pp，6/6 种子零例外，
  不走 d_ent 通道）
- 决策人：Lance（用户）；执行：WorkBuddy（无涯智）

## 一、问题

同层横向自连接（REC：z ← z + σ(lat(z))·z，推理时贡献
为零）在 ID 无差的情况下使 c100 探针迁移 +4.0pp。三候选
机制：

- **M-平滑**：训练时的横向调制起「特征平均」作用——等价
  于对表征做平滑正则，改善探针可读性；
- **M-增广**：横向通路的随机性（初始化+梯度噪声）等价于
  隐式数据增广——测试时虽关掉，训练正则化收益留下；
- **M-集成**：横向自连接等效于同层多视角的轻量集成——
  探针读出时特征更稳定。

判别性预测（跑前写死）：

| 机制 | 训练后特征扰动敏感度↓ | dropout 等价正则替代应复现 | 特征稳定性↑ |
|---|---|---|---|
| M-平滑 | 是 | 否 | 是 |
| M-增广 | 否 | 是 | 否 |
| M-集成 | 否 | 否 | 是 |

## 二、N4 设计（跑前冻结）

### N4a（机制判别，12 run）

1. **P 臂（扰动敏感度，6 run）**：REC 与 FF 各 3 种子，
   训练后对 penultimate 特征注入高斯噪声 σ∈{0, 0.1, 0.3}
   （×单位方差归一），测 c100 探针随 σ 的衰减曲线。若 REC
   的衰减显著慢于 FF → 特征更稳健（M-平滑/M-集成预测）；
   若无差 → M-增广方向。
2. **D 臂（dropout 等价对照，6 run）**：FF + 特征层
   dropout p=0.1（训练时施加于 penultimate，等价正则替代）
   × 3 种子 vs FF 原配 3 种子（N1″ 复用）。若 FF+dropout
   复现 +4pp → M-增广（正则化通道）成立。

### N4b（边界，12 run）

REC/FF 各 3 新种子（6/7/8）× CIFAR-10-C 评估（19 种腐蚀
×5 强度，官方口径）：效应是否在分布外腐蚀上复现、哪些
腐蚀类型受益最大。6 run 训练 + 复用 N1″/N2b 的 12 个已有
checkpoint 一起评（零额外训练）。

### 判读（冻结）

- **J1（P 臂主判读）**：σ=0.3 时 REC 与 FF 的 c100 衰减差
  ≥ 2pp → 「特征稳健性」通道（M-平滑/M-集成族）；无差
  → M-增广方向（由 J2 裁决）。
- **J2（D 臂）**：FF+dropout(0.1) 的 c100 − FF ≥ +2pp
  → M-增广成立（正则化通道可复现效应）；否则 M-增广
  排除——若 J1 同时无差 → 三机制全否，挂 M-其他（描述
  横向通路的具体作用面）待 N5。
- **J3（N4b）**：REC−FF 的腐蚀 acc 差均值 ≥ +1.5pp 且
  ≥13/19 腐蚀同向正 → 效应泛化到真 OOD；否则效应是
  c100-探针特异（记录边界）。
- **J4（健康闸）**：全部新训 run id_test ≥ 0.90。

## 三、N4 跑后段（占位，跑后填）

## 三、N4 跑后段与收口（2026-11-16 11:35，跑后如实记录）

15/15 run + P 臂衰减评估 + N4b 腐蚀评估完成（两处执行勘误：
①评估脚本 ckpt 路径写错找 n1p（实际在 n4_*），修后重评；
②腐蚀数据是官方 .npy 格式非 ImageFolder，评估器改写）。

### J1（P 臂扰动衰减）：稳健性通道否决

| σ | FF c100 | REC c100 | REC−FF |
|---|---|---|---|
| 0 | 0.0963 | 0.1359 | +0.0396 |
| 0.1 | 0.0965 | 0.1355 | +0.0389 |
| 0.3 | 0.0946 | 0.1327 | +0.0382 |

**σ=0.3 时差仅缩水 0.14pp（门槛 2pp）**——两配置的衰减
曲线几乎平行（各自掉 ~3pp），REC 的优势不随噪声增长。
特征稳健性（M-平滑/M-集成）**不承载**该效应。

### J2（D 臂 dropout 复现）：正则化通道否决

FF+feat-dropout(0.1) 的 c100 = 0.0961 vs FF 0.0961（差
+0.01pp）——**完全不复现**（REC 同批 +4.0pp）。head 输入
dropout 的正则化不是效应载体。d_ent 对照：FF+do 2.62 vs
REC 3.36——dropout 也没有产生 REC 的几何扩张。

### J3（N4b 腐蚀泛化）：边界否决——效应是探针特异的

CIFAR-10-C（19 腐蚀 × 5 强度，3 种子）：REC−FF 均值
**−0.03pp**，正向腐蚀仅 9/19（门槛 13/19 且 +1.5pp）。
**REC-OOD 效应不泛化到输入分布腐蚀**。逐腐蚀有结构：
pixelate +3.1pp / gaussian_noise +1.4pp（数字化与噪声类
受益）vs glass_blur −1.9pp / frost −1.6pp（模糊冰冻类
受损）——但整体抵消。

### J4：全过（最差 0.947）。

### 合并判读：REC-OOD 效应的定性

三机制（平滑/增广/集成）全否 + 腐蚀不泛化 → 按 J1/J2 的
既定分支：**挂 M-其他**。效应画像收敛为：**横向自连接改
善的是「c100 线性探针可读性」（表征对 100 类线性可分性的
协议内度量），而非真实的分布外鲁棒性**——它是表征空间的
重组使 CIFAR-100 类边界在 linear probe 下更可读，与输入
级腐蚀鲁棒性正交。这与 ADR-0016 的核心论题意外呼应：
「几何/表征层面的改善 ≠ OOD 泛化改善」——REC-OOD 是该
论题在架构干预维度的又一例证。

### 处置
