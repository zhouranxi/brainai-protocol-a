# ADR-0029：Predictive-Coding 反馈——门控探针（PC-A0）

- 状态：已收口（PC-P2 FAIL +0.05pp vs 门槛+2.2pp；PC-P1 方向反 ρ=-0.97——误差坍缩；五路全灭最终确认，PC-B 不启动）
- 日期：2026-11-21 20:40 立项
- 依据：ADR-0024 收口后登记的残余解释——「增益需要与训练目标耦合
  （predictive coding 的自监督损失），而非任何形式的信息通路本身」。
  四路全灭（调制/瓶颈/门控信念/LLM prompt）全部是**外加残差、不参与
  损失**的反馈；PC 反馈携带预测误差并参与损失，是同量级下机制真正
  正交的第一候选。
- 决策人：Lance（用户）；执行：WorkBuddy（无涯智）
- 资源：学校机 GPU2/3（用户确认可用）；预算 ~6 GPU·h（探针批）

## 一、机制差异（与已灭四路的对照，跑前写死）

| 已灭路径 | 反馈内容 | 是否参与损失 | 失败模式 |
|---|---|---|---|
| HFB 调制（0019） | 恒等自连接×门控 | 否 | 幅度塌零 |
| 瓶颈 HFB（0022） | 同上（三瓶颈下） | 否 | 瓶颈不变零增益 |
| BFM 信念（0024） | 消歧指令残差 | 否 | b 塌缩 + 双前向自伤 |
| LLM prompt（0023） | 层级分解文本 | 否 | 无层级特异增益 |
| **PC（本 ADR）** | **逐层预测误差** | **是（重构损失项）** | 待测 |

关键差异：PC 的反馈信号（预测误差）**由损失函数训练出来**——
低层特征的预测器必须真的预测得准，误差才小；误差回传本身就是
学习目标的一部分。这与「外加信息通路」在梯度结构上不同类。

## 二、架构（最小 PC 测试架）

在 resnet18 主干上逐层加**侧向预测器**（轻量 1×1 conv 头，预测
下一层特征，停梯度于目标）：

- L 层特征 z_l → 预测器 p_l(z_l) ≈ sg(z_{l+1})，重构损失
  L_pc = Σ_l ||p_l(z_l) − sg(z_{l+1})||² / d；
- 总损失 = CE + β·L_pc，β ∈ {0.1, 1.0}（β=0 即 FF 基线，同代码路径）；
- **推理时无附加计算**（预测器仅训练期使用）——与 BFM 的双前向
  自伤不同，这里没有推理期开销；
- 参数配平：预测器参数计入，FF 臂加等量 dead 参数对照（或报告
  参数差并按 0022 的口径处理——HFB 系列已证 ±0.5pp 内参数差不构成
  混杂）。

## 三、PC-A0 三探针（跑前冻结，全部沿用 ADR-0024 表 3-1 精神）

训练完成后立即执行，不得跳过：

| 探针 | 观测量 | 判据 |
|---|---|---|
| **PC-P1 误差响应** | 各层预测误差 e_l 随输入遮挡 severity（0→5）的变化方向 | 误差随遮挡**上升**（ρ ≥ +0.8）——遮挡下预测更难，误差应增大；方向反 = 反馈未编码输入结构 |
| **PC-P2 消融伤害** | 推理时去掉预测器（本就无推理开销）vs 训练时 β=0 的差 | β>0 相对 β=0 的 ID 增益 ≥ +2.2pp（超出噪声带）——PC 损失带来真实行为增益；无增益 = 第五路全灭确认 |
| **PC-P3 归因保护** | 只缩放重构目标范数（sg 目标乘常数 c，误差同缩） | 标量效应 < PC-P2 增益的一半 | 

**门判定（冻结）**：
- PC-P1 方向反 或 PC-P2 增益 < +2.2pp → **PC 线否决**，五路全灭
  图景成立，「该量级测试架上反馈增益不可得」升级为最终结论；
- PC-P1 过 + PC-P2 过 + PC-P3 过 → **增益窗口存在** → 立项
  PC-B（评估文档实验 B 的四臂裁决，对预测误差表征施加
  recolor/rotate——原方案的裁决仪器直接启用）；
- PC-P2 边缘（+1~2.2pp）→ 补种子（3→6）再判，预注册此条款。

## 四、PC-A0 跑后段与收口（2026-11-21 23:50，跑后如实记录）

9/9 完成（beta {0, 0.1, 1.0} × 种子 {0,1,2}，sev-3 遮挡训练，
200ep，双卡 ~2.9h，零错误）。判读按冻结条款：

### PC-P2（消融增益）FAIL——离门槛差 44 倍

- beta=0.1 平均 @s0 增益 **−0.29pp**（−0.41/−0.65/+0.18，符号不一致）；
- beta=1.0 平均 @s0 增益 **+0.05pp**（−0.07/+0.10/+0.13，噪声带内）；
- 门槛 ≥ +2.2pp（ADR-0024 修正后的噪声带外阈值）。
- **PC 重构损失没有带来任何行为增益**——与四路已灭路径
  完全同型：±0.5pp 噪声带内的零。

### PC-P1（误差响应方向）FAIL——方向再次反转

预测误差随遮挡 severity **单调下降**（全 6 个 run ρ =
−0.92~−0.98，门槛 ≥ +0.8）：遮挡越重，各层预测误差越小。
方向与预测完全相反。

### P1 反转的机制解读（新增信息，值得记录）

这不是「预测器没在工作」——误差有量级（0.07–0.14）且
逐层分化。反转的机制是**表示坍缩**：遮挡越重，主干特征
分布越收缩，后续层特征越接近低方差的「安全」表示，预测
越容易。这与 ADR-0024 的 b 塌缩（信念状态在难输入下退化为
常数）是同一现象的两个读法：**本量级的网络在难输入下的
默认响应是收缩表征，而不是展开消歧**。「层级先验引导
推理」假设的网络行为——难输入触发高层先验下行消歧——
在 ResNet-18/CIFAR-10 上从未发生，五条实现路径一致指向
这一点。

### 判定：PC 线否决，五路全灭收口

按冻结条款：PC-P2 FAIL → **PC 线否决，PC-B 四臂裁决不
启动**。「层级先验引导推理」产品线在 ResNet-18/CIFAR-10
量级的最终结论：

> 五条机制上独立的反馈实现路径（激活调制 / 瓶颈下调制 /
> 门控信念注入 / LLM 层级 prompt / 训练目标耦合的
> predictive coding），在同一测试架上全部零或负增益；
> 其中两路出现与预期完全相反的方向性（信念塌缩、误差
> 坍缩）。反馈增益在该量级的缺席是系统性的，且伴随
> 「难输入→表征收缩」这一与引导假设相反的默认行为。
