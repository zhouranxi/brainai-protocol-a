# ADR-0035：M-d 截断行的打分位置——人工判读批

- 状态：预注册（2026-11-27 12:02 冻结，读数据前）
- 决策人：Lance（"先 A 后 B"，2026-11-27 11:59）；执行：WorkBuddy
- 依据：机制文 Limitations「Unequal output budget」与测量伪影节「Residual truncation, disclosed」各有一句断言——截断"不触及被打分的列表"（*The cut does not reach the scored list*）。该断言的依据是截断组与完整组 top-1 相近（65% vs 66%）。**该依据不充分**：rank 相近不证明打分位置相同。若截断行的 rank 是打分器从推理段落里取到的（例：P31 G2 rep0 末句 `**"风驰电掣"** 的把握度真的是95%吗？` 被 item 化），则测到的是"推理中提到的置信度"而非"最终承诺"。

## 一、问题

R1200（1200 token，与论文口径一致）的 M-d 截断行中，**截断点之前存在最终承诺**的比例是多少？

## 二、判读规则（冻结）

**最终承诺** = 输出在截断点之前，明确给出一个"按把握排序的 ≥3 个候选"的集合，且该集合被表述为**最终的/当前的**判断（而非某假设分支下的、或"原始候选"的、或被明确否决/待修订的列表）。

认作承诺的格式（任一即可）：
- N 编号列表 `1. X 把握：a%` / `1. X a%`（含 `#### 1.` 等标题式编号）
- T Markdown 表格，含候选与百分比列
- B 子弹列表，每项带百分比
- A 单行 `X(a%) > Y(b%) > Z(c%)`

**判为"无承诺"**（任一成立即无）：
- U1 截断点前只有推理/散文，没有任何 ≥3 带百分比的候选集合
- U2 有带百分比的列表，但明确是**假设分支**（"假设谜题不限定成语：…"）或"原候选集"的复述，且其后开始"综合判断/最终/修订"段而**在该段内被截断**
- U3 有 ≥3 候选集合但**不带百分比**
- U4 列表的第 3 项或其百分比**本身被截断**（列表不完整）

**歧义处理**：判读者对单条不确定时标 `?`，不计入主比例；报告时给出"含 ? 为承诺 / 含 ? 为无承诺"的上下界。主读出 = 无承诺比例的点估计与 Wilson 95% CI。

**次要读出**：
- 无承诺行的 rank 分布（重点：rank==1 的比例——这些是"打分位置不是承诺"的行）
- 承诺格式分布（N/T/B/A/U4），验证"格式失控"
- R2400 同法抽 30 条作对照（预期无承诺比例显著更低）

## 三、判读与闸门

- **R-C1（断言需撤回）**：R1200 M-d 截断行中无承诺比例的 Wilson 95% CI 下界 ≥ 25% → "截断不触及被打分列表"不成立，机制文两处改写为"截断行中 X% 在截断点前无最终承诺，其 rank 取自推理段落"
- **R-C0（断言维持）**：CI 上界 < 25% → 断言维持，补一句实测比例
- 落在两者之间：如实报告，判读者不得加样（见下）

**样本量固定**：R1200 截断行随机抽 60 条（seed=20261127，无放回），R2400 截断行抽 30 条（全部 48 条中抽）。**不得因结果接近边界而加样**——加样即另立 ADR。60 条下若真实比例为 50%，Wilson CI 半宽约 ±12.6pp。

## 四、盲化

判读者（WorkBuddy）**读文本前不看到 rank**：抽样脚本只输出 (id, 文本)，rank 在判读完成后由脚本合并。判读结果逐条落盘（`results/p36_commit/judgments.jsonl`），可复核。

## 五、与论文的关系

- R-C1 → 改写 Limitations「Unequal output budget」与「Residual truncation, disclosed」中相关句；不改任何 rank 数字（rank 仍是打分器的忠实输出，变的是"它测的是什么"的解释）
- R-C0 → 补一句实测比例
- 两种情况下 R2 否定判决（ADR-0031）、R-T0（ADR-0034）均**不重判**——本批只判读打分位置的语义

## 六、不做

- 不重跑任何模型调用
- 不改打分器
- 不据本批结果改表 2 / §early 数字
