# ADR-0034：P31 确认批全文重跑 + M-d 截断解除臂

- 状态：预注册（2026-11-24 23:58 冻结，发射前）
- 日期：2026-11-24 23:54 用户授权重跑
- 依据：P34 审计（`code/p34_scorer_audit.py`）发现 P25 v2 批 M-d 截断率 57.8%；P31 确认批（2160 条）未存全文，截断无法量化；机制文 v0.6 Limitations "Unequal output budget" 披露该空白
- 决策人：Lance（用户）；执行：WorkBuddy（无涯智）

## 一、问题

P31 确认批在 `max_tokens=1200` 下运行，M-d（自我批判）输出中位 1991 字符，58% 在句中被截断。
截断不改变已记录的 rank（候选列表在截断点前），但 M-d 是唯一在"预算经常用尽"约束下被观察的机制。
两个未答问题：

- **Q1**：P31 确认批的 M-d 截断率是否与 batch-1 一致（≈58%）？
- **Q2**：解除截断（2400 token）后，M-d 的行为是否变化？具体指提前收敛曲线（G1/G2/G3 top-1）与 dup 分布。

## 二、设计

### 臂

| 臂 | max_tokens | 机制 | 目的 |
|---|---|---|---|
| **R1200** | 1200 | a/b/c/d 全部 | 忠实重跑：复现 P31 条件，存全文 + `finish_reason` + M-d 的 `base` |
| **R2400** | 2400 | 仅 d（可选 c 作对照） | 截断解除臂：M-d 在不被截断时的行为 |

- 题目：P31 的 60 题（`runs/v2_p31/p31_puzzles.json`），不生成新题
- 温度：0.7 × 3 重采样，与 P31 一致
- 调用：`http://localhost:8543/v1/chat/completions`，`enable_thinking: false`，与 P31 一致
- 输出：`runs/v2_p35/p35_race_{1200,2400}.json`，每行含 `text`、`base`（M-d）、`finish_reason`、`base_finish_reason`
- M-d 的 `base` 调用（内部 `run_mech_t("c")`）在 R2400 臂同样用 2400

### 判据（跑前冻结）

**Q1 判读**（描述性，无闸门）：
- 用 `finish_reason == "length"` 作截断判据（主），启发式 `len>800 & unterminated`（辅，与 P34 对接）
- 报告 R1200 各机制截断率；与 batch-1 的 57.8/7.8/4.4/0 对比

**Q2 判读**（有闸门）：
- 主读出：M-d 的 top-1 按 grade（G1/G2/G3），R2400 vs R1200
- **R-T1（截断有行为影响）**：R2400 与 R1200 的 M-d top-1 在任一 grade 相差 ≥ 10pp 且 sign test p < 0.05 → 截断是行为混杂，机制文 §early 需加限定
- **R-T0（截断无行为影响）**：三 grade 差值均 < 10pp 或 p ≥ 0.05 → 截断是测量伪影，不影响行为结论；机制文 Limitations 可改写为"已验证不影响"
- 次要：R2400 的 dup 分布 vs R1200；R2400 的 `base` 截断率（预期接近 0）

### 不做的

- 不改题目、不改温度、不改机制 prompt（除 max_tokens）
- 不重判 R2（ADR-0031 的 +3.3pp 否定判决零回改）
- R2400 臂若 M-d 输出仍 > 2400 token 被截，如实报告，不再加码

#### Q1 截断普查（描述性，无闸门）

截断判据 = API 原生 `finish_reason == "length"`（主）；辅助列为 P34 启发式 `len>800 且未以句末符结尾`。

| 机制 | 截断/行数 | API 截断率 | P34 启发式 | batch-1（启发式） | 输出中位字符 | p90 |
|---|---|---|---|---|---|---|
| M-d 自我批判 | 329/540 | **60.9%** | 48.3% | 57.8% | 1954 | 2097 |
| M-c 假设维护 | 38/540 | 7.0% | 5.4% | 7.8% | 1062 | 1705 |
| M-a 无状态 | 9/540 | 1.7% | 3.0% | 4.4% | 658 | 1129 |
| M-b 锁定 | 0/540 | 0% | 0% | 0% | 4 | 331 |

- **Q1 回答：与 batch-1 同量级，M-d 更严重**（60.9% vs 57.8%，+3.1pp）；M-c、M-a 均略低于 batch-1。05:02 的中途抽样（n=207/机制，M-d 66.7%）是高估，全量落在 60.9%。
- M-d 按级别：G1 71/180（39.4%）、G2 132/180（73.3%）、G3 126/180（70.0%）。G2 起批判步要复述更长的多轮候选，结构性超 1200。
- **M-d 的 base_finish_reason**：stop 500（92.6%）、length 40（**7.4%**）；按级别 G1 0/180、G2 20/180（11.1%）、G3 20/180（11.1%）。与 R1200 独立跑的 M-c（7.0%）一致——同一 prompt、同一 cap。
- 329 条 M-d 截断行中，base 步也被截的 37 条（11.2%）；**88.8% 的截断落在批判调用本身**。
- 两种判据的差异（M-d：API 判截 329、启发式判截 261）：API 判截而启发式判完整的 70 行，是因为 1200 token 边界恰好落在句末（末字符 `。`28、`*`30、`.`4 等），句子完整但后文被切；启发式低估。**API 原生标志为准**，与预注册一致。
- 截断与 top-1 的关系（行级，M-d）：G1 截断 32/71（45.1%）vs 完整 46/109（42.2%）；G2 84/132（63.6%）vs 32/48（66.7%）；G3 90/126（71.4%）vs 34/54（63.0%）。方向不一致、幅度在噪声带内，与 batch-1「65% vs 66%」同质。**这只是描述性对照，不是 Q2**——截断与否不是随机分配的，Q2 等 R2400。

#### 一致性检查（R1200 重跑 vs 原 P31，同一 60 题，temp 0.7 × 3）

G3 top-1，按题取 3 次重采样中位 rank（论文口径）：

| 机制 | G1 P31 → R1200 | G2 P31 → R1200 | G3 P31 → R1200 | G3 行级 P31 → R1200 |
|---|---|---|---|---|
| M-a | 41.7 → 41.7（+0.0） | 45.0 → 43.3（−1.7） | 75.0 → 76.7（+1.7） | 71.1 → 71.7（+0.6） |
| M-b | 25.0 → 28.3（+3.3） | 35.0 → 35.0（+0.0） | 76.7 → 78.3（+1.7） | 77.8 → 79.4（+1.7） |
| **M-c** | 30.0 → 35.0（+5.0） | **43.3 → 58.3（+15.0）🔴** | **80.0 → 70.0（−10.0）🔴** | 68.3 → 63.3（−5.0） |
| M-d | 46.7 → 48.3（+1.7） | 73.3 → 73.3（+0.0） | 73.3 → 75.0（+1.7） | 67.2 → 68.9（+1.7） |

- **判定：一致性检查不通过（M-c 两格 ≥ 10pp），按规则标红、不改 main.tex。** M-a、M-b、M-d 十二格中最大 |Δ| = 3.3pp，重跑稳定。
- M-d（本批研究对象）三格 +1.7 / 0.0 / +1.7pp，逐题中位 rank 一致率 67.2%，top-1 指示翻转 50/180——temp 0.7 下的正常重采样抖动，不是系统偏移。
- **M-c 红标的性质（exploratory，不重判）**：行级 top-1 两批几乎重合（G1 29.4→31.1、G2 46.1→48.3、G3 68.3→63.3，最大 5.0pp）；红标全部来自「3 次取中位」口径的放大。每题 3 个 0/1 指示的中位数，在概率≈0.5 的格子里抖动大：P31 自身三次重采样的行级 top-1 在 M-c G2 就跨 40.0%–51.7%（11.7pp）。独立佐证：M-d 的 base 步是同一 M-c prompt，独立打的 540 条，行级 top-1 = 30.0 / 49.4 / 61.7，与两批 M-c 同带。配对 sign test（中位口径）：G2 R1200 胜 15 / 负 6，p = 0.078；G3 胜 10 / 负 16，p = 0.33，均不显著。
- **对论文数字的含义（exploratory 合并 90 题重算，batch-1 30 题固定，确认批换成 R1200）**：M-a 41/46/68 → 41/45/69；M-b 27/33/68 → 29/33/69；M-c 30/37/66 → 33/46/60；M-d 43/63/69 → 44/63/70。终局 M-d − M-c：P31 为 +3/90（+3.3pp，CI [−7.8, +14.4]），R1200 为 +10/90（+11.1pp，CI [−1.1, +23.3]）；M-d vs M-c 配对 sign test：G1 20/7 (p=.019) → 21/10 (p=.071)，G2 32/6 (p<1e-4) → 26/9 (p=.006)，G3 16/13 (p=.71) → 21/11 (p=.11)。R1 的召回差（M-c − M-a，top-3，合并 90 题）：G1/G2 由 P31 的 11/90、30/90（+12/+33pp）变为 R1200 的 14/90、38/90（+16/+42pp），方向一致、量级不变。
- **解读**：论文表 2 的 M-c 列（30/37/66）对「用哪一次 60 题重采样」敏感——差值几乎全部来自 M-c 的移动（M-d 基本不动：43/63/69 → 44/63/70）。同口径下重跑一次，终局差从 +3.3pp 变成 +11.1pp，方向不变（M-d 略高），CI 两次都跨 0，p 两次都 > 0.05，**R2 否定判决在两次数据上都不翻**。但 G1 的「早期领先显著」（p=.019）在重跑上不再显著（p=.071），G2 仍显著（p=.006）。这是 M-c 作为对照臂的重采样不稳定性，记为开放问题，不回改 ADR-0031 判决与论文表 2。

### 开放问题（随批记录，不开新实验）

1. **对照臂 M-c 的重采样稳定性**：同一 prompt、同一 temp，重跑一次，中位口径 G2/G3 各移动 15/10pp。论文的早期领先结论（G1 p=.019 → .071）依赖单次 60 题重采样。可考虑的处置（需 Lance 定）：(a) 论文改报行级或合并重采样口径并披露；(b) 加重采样次数提高每题中位数的稳定性；(c) 维持现状、在 Limitations 加一句披露。
2. **G1 早期领先的显著性对 M-c 重采样敏感**，见上。
3. R2400 在 2400 token 下仍有残余截断，阶段 B 看全量比例，再定「解除臂」是否名实相符。
