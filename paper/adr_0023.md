## 一、问题

「层级先验引导推理」在 LLM 语境下的操作化：把**层级结构**
（任务分解层级 / 概念从属层级）作为先验注入推理过程。
核心裁决沿用架构线的同构范式——层级结构的增益载体是
**注入侧**（什么时机给）还是**结构本身**：

- **H1（结构假说）**：层级结构本身携带对推理有用的信息
  （步骤间的从属/依赖关系），无论怎么给都应有增益；
- **H2（注入侧假说）**：同样的结构信息，以不同时机/形式
  给出效果不同（分解在前 vs 逐步揭示 vs 结果对照），
  增益主要来自注入方式与推理动力学的匹配。

## 二、设计（跑前冻结）

### 因子矩阵（每题 × 8 条件）

| 条件 | prompt 形式 | 检验 |
|---|---|---|
| C0 flat | 直接问题，无结构 | 基线 |
| C1 hier-decompose | 层级任务分解（顶层目标→子任务树）一次性前置 | H1：结构前置 |
| C2 hier-stepwise | 同一分解树，但按推理进度逐步揭示（多轮） | H2：时机 |
| C3 flat-decompose | 非层级平铺步骤清单（同样的步骤数，去掉从属结构） | **结构对照（关键）** |
| C4 concept-hier | 概念从属层级（不分解任务，只给概念树） | 结构类型对照 |
| C5 reversed | C1 的分解树节点乱序打乱 | 结构有效性对照 |
| C6 hier-post | 推理完成后再给分解（应无增益——安慰剂） | 安慰剂闸 |
| C7 verbose | 与 C1 等长度的非结构填充文本 | 长度对照 |

- **数据**：GSM8K 测试集随机 100 题（数学多步推理，结构
  敏感的经典域）；温度 0；每题每条件 1 次（确定性解码下
  重复无益，省预算）。
- **模型**：批 A = 本地 Qwen3-7B（Ollama，零成本）；批 B
  （可选，用户拍板后）= 更强模型 API 复核。
- **评分**：GSM8K 数字答案精确匹配（自动）；记录 token 数
  （长度成本）。

### 判读（冻结）

- **L1（主裁决：结构增益）**：C1−C0 ≥ +5pp → 层级分解
  有增益；**C1−C3 ≥ +3pp** → 增益特异于「层级」而非
  「步骤清单」（H1 的严格版）；C1≈C3 → 增益来自步骤化
  本身，层级无关；
- **L2（时机裁决）**：C2−C1 ≥ +3pp → 逐步揭示优于前置
  （注入侧重要，H2 支持）；|C2−C1| < 3pp → 时机不敏感；
- **L3（安慰剂与对照闸）**：C6−C0 < 3pp（事后给无效，
  否则实验无效）；C7−C0 < 3pp（非长度效应）；C5 < C1
  （乱序损害结构有效性）；
- **L4（概念层级）**：C4−C0 与 C1−C0 对照——任务分解
  vs 概念层级哪种先验有效；
- **L5（成本）**：各条件 token 数对照表（增益是否值得）。
- 任何条件若 C0 本身 < 20% 正确率（模型太弱）或 > 85%
  （天花板），该批判无效（健康闸，批 B 换模型）。

### 判读：L5b 健康闸 FAIL——**天花板效应，整批判无效**

**C0 基线 97%**（预注册健康区间 20–85%）——qwen3:8b 对
GSM8K 前 100 题接近饱和：96 题双对（C1/C3 逐题对照），

噪声，无分辨力。**判读不适用，按冻结条款整批判无效**。

### 唯一可说的（描述性）

各结构条件的 token 数反而更低（871–992 vs 1303）——分解
提示缩短了推理长度（−25–35%），在正确率持平下是效率
收益。但这是天花板下的观察，不入判读。
