# 备忘录：从五路全灭到「怎么发现新架构」

2026-11-21 深夜 · 基于本文库 14 个 ADR / ~700 run 的全部证据 · 不预注册，供决策参考

## 一、先把证据读成一句话

五条机制独立的反馈路径全灭 + 两次方向反转（信念塌缩、误差坍缩）+
深度亚临界（容量利用率 0.2%–3.5%）拼成一幅完整图景：

> **架构创新是对「压力」的响应。我们的测试架上没有压力——
> 任务用 0.8% 的容量就解决了，目标函数还奖励表征收缩——
> 所以任何外加机制都没有东西可买。**

这不是「反馈没用」的一般结论，而是「无压力处无增益」的
结构结论。Transformer 诞生于序列信息检索压力，扩散模型诞生于
数据生成目标，CoT/自修正诞生于 LLM 在难任务上的信息瓶颈。
**先有约束，后有架构**——我们 17 天学到的正是它的逆否命题：
没有约束，加什么都是零。

## 二、三次方向反转给了两条可用的「负向发现」

1. **难输入 → 表征收缩是本量级的默认行为**（b 塌缩、误差坍缩
   两次独立复现）。目标函数没有奖励「难输入下保持信息」——
   收缩是 CE 的理性最优解。这意味着：**换接线不会改变这个
   默认行为；要改变它得换目标**。
2. **误差坍缩是一个便宜的探针**：逐层预测误差随输入难度的
   方向（ρ 的符号），一次前向就能测。它可能可以区分「抗坍缩」
   与「坍缩」的训练配方/架构——五路全灭送给我们的一件工具。

## 三、三条真实路径（按「压力从哪来」分类）

### 路径 A：去有压力的量级——LLM 微调级反馈（最接近文献中真实增益的位置）

文献里反馈确实产生增益的地方（CoT、self-correction、speculative
decoding）全部在**推理天生迭代**的大模型上。我们的零结果在
小分类器上干净，但对外效度（external validity）未被检验。

- **最小实验**：Qwen3-8B + QLoRA（双 V100 16G 或 3090 24G 可跑），
  难任务上基线落在可分辨带（20–85%，白皮书 §2）；
- **门控先行**（老规矩）：先测「反馈结构是否改变内部状态方向」
  ——LLM 版 PC-P1，~几小时；
- **预算**：门控 ~5 GPU·h，全批 ~30 GPU·h；
- **风险**：文献拥挤（自修正已大量发表），我们的增量在
  「预注册门控判读 + 方向探针」方法论，不在现象本身。

### 路径 B：换目标不换接线——反坍缩目标下的反馈再测（直接继承今晚发现）

假设：反馈增益需要目标函数先奖励「难输入下保持信息」。

- **第一步（便宜，先做）**：在既有测试架上把 CE 换成
  CE + 一致性/对比项（腐蚀前后特征一致性），零训练批先测
  **误差坍缩方向是否翻转**（ρ 从 −0.97 → ≥0）——用我们已有的
  探针代码，~4 GPU·h；
- **若方向翻转**：在该目标下重跑 PC-A0（β 扫描）——这是
  五路全灭后唯一有机制理由的「第六次尝试」；
- **若不翻转**：坍缩比想象更深（架构性而非目标性），路径 B
  关闭，这个负结果本身可写进 sequel。
- **这是我认为科学上最诚实的一条**：它先解释反转、再利用反转。

### 路径 C：把坍缩探针变成架构筛选器（零训练，全用既有资产）

- 对既有 68 checkpoint（+ 可扩展 ViT / 不同训练配方）测
  **误差方向 ρ**，问：哪些训练配方/架构族天然抗坍缩？
- 与 utility/L_knn 并入 marker 家族——「坍缩抗性」作为一个
  新 marker，如果它跨族稳定且与 c10c 相关，就是
  measurement 论文的第二篇 sequel 直接素材；
- **预算**：~2 GPU·h（特征提取批，管线现成）；
- 产出无论正负都可发表（marker 论文范式已验证）。

## 四、明确不做的（同样重要）

- **NAS/自动搜索**：在无压力测试架上只会重新发现 ResNet 变体；
- **第六种手接线的反馈**（attention 反馈、跨层门控 CNN……）：
  与已灭五路机制同类，先验概率已被证据压到地板；
- **等生物数据**（原方案科学问题 5）：依赖外部，不可控，挂起。

## 五、建议（如果要继续）

**C 先行（2 GPU·h，本周）→ B 第一步（4 GPU·h，紧随）→
按 B 的翻转结果决定 B 第二步或转 A。** 每步都过门控，每步
都是独立可发表的单元。若 C/B 全负，则「新架构」问题的诚实
答案留在本文档第一节，项目回到论文收尾与投稿线。

## 后记（2026-11-22 上午，P23 跑后修正）

P23（路径 C，68 checkpoint 坍缩探针批）跑出了一个**修正性发现**，
改变了备忘录第一节的合成判断：

### 修正：坍缩不是「本量级的默认行为」，是「在难分布上训练」的适应

三条件对照（同一探针、同一 severity 轴）：

| 训练条件 | resnet18 ρ（误差方向） | 读法 |
|---|---|---|
| **干净训练**（ckpt_grid，n=52） | **中位 +0.937**（范围 −0.99~+1.00） | 难输入下误差**上升**——表征不坍缩，正常方向 |
| **遮挡训练**（PC-A0，sev3，200ep，n=6） | −0.92 ~ −0.98 | 难输入下误差**下降**——坍缩 |
| **遮挡训练短批**（P24-ce，sev3，60ep，n=1） | −0.987 | 同上，60ep 已完全形成 |

PC-A0 的「误差坍缩」不是架构缺陷，而是**网络对训练分布的
理性适应**：在遮挡分布上，把难输入映射到低方差安全表征就是
CE 的最优解。五路反馈全灭的真正语境由此改写——**不是「反馈
在这个量级没用」，而是「测试架（遮挡训练）主动训练出了与
引导假设相反的表征行为；在这个行为之上叠加任何反馈机制都
是在对抗已训练进去的解」**。

其余 P23 读数（如实）：

- rho_collapse 与 c100 相关 +0.04（配对 40）——坍缩抗性**不是**
  泛化 marker；与 D_eff/U 相关 0.12/0.16——独立但不携带迁移
  信息。**C 路径的 marker 化不成立**（按备忘录预期处置：
  不立项，只记录）；
- resnet18 内部 ρ 按 lr 不分化（四个 lr 组中位全在 +0.91~+0.95）
  ——干净训练下坍缩方向一致为正，recipe 不影响；
- 范围 [−0.988, +0.997] 说明 68 模型里有少数翻转个体（4 个
  ρ<−0.5）——值得注意它们全部落在 ckpt_grid 的高 lr 尾部
  （lr=1.0 组含 2 个），这些是「在干净训练里就部分坍缩」的
  个例，登记不深挖。

### 对路径 B 的直接指令

B1（P24，CE vs CE+cons）的 ce 臂首种子已确认复现坍缩
（ρ=−0.9865）。cons 臂的判读因此变得更干净：**如果一致性目标
能把 ρ 从 −0.99 拉回 ≥0，就证明坍缩可以被目标函数解除——
「表征收缩是目标选出来的，因此也可以被目标改掉」**。这将
是五路全灭之后第一个积极的机制证据，PC-A0 重跑（第六次尝试）
的触发判据照旧（cons 臂 ≥2/3 种子翻转到 ≥0）。P24 cons 臂
在跑（GPU3，ETA ~11:00）。

## 后记二（2026-11-22 10:20，B1 跑后判读）

P24（CE vs CE+cons，6 run）收判。**冻结门不过**：

- ce 臂 ρ：−0.987/−0.988/−0.976（坍缩精确复现）；
- cons 臂 ρ：−0.984/−0.987/−0.981（**0/3 翻转**）；
- 附带读数：cons 臂的特征范数收缩反而更深（norm@s5/s0
  0.51 vs ce 0.85）——一致性项把遮挡特征往干净特征拉，
  但干净特征本身在该网络上也低范数，结果坍缩更深；
  acc@s5 略有改善（0.20→0.23，噪声级）。

**判读：一致性目标解不了坍缩。** B 路径的第一步失败，
按冻结条款 **PC-A0 重跑（第六次尝试）不触发**。

### 合并结论（P23 + P24，坍缩问题的完整答案）

1. 坍缩是**训练分布适应**（P23：干净训练 ρ=+0.94 正常）；
2. 坍缩**不可被简单一致性目标解除**（P24：cons 0/3 翻转，
   且范数收缩更深）；
3. 因此坍缩处于「CE+该分布训练出的稳态解」——它不是
   随机噪声，是分布与目标联合选出的吸引子。要解除它需要
   更强的正则（更强的数据增强多样性、难例挖掘、或显式
   信息量目标），但那些已经超出「给反馈机制一个公平机会」
   的范围——那是在改训练问题本身。

### 备忘录三条路径的终局

- **C（坍缩 marker）**：不成立（r(rho,c100)=+0.04）——记录；
- **B（换目标救反馈）**：第一步失败，第六次尝试不触发——
  按备忘录 §五 的纪律，B 路径关闭；
- **A（去有压力的量级）**：成为唯一开放路径（LLM 微调级
  反馈，~35 GPU·h，文献拥挤但方法论有增量）。

### 「怎么发现新架构」的最终答案（本备忘录收口）

十七天 + 两批后续实验把答案收敛为一句话：**在本测试架上，
不存在通过架构接线或目标微调可得的引导式反馈增益——
因为训练分布与目标已经联合选出了与引导假设相反的表征
行为（坍缩吸引子），且该吸引子对一致性正则鲁棒。** 新
架构的发现空间不在「这个测试架上再试一种」，而在换一个
训练问题：要么去 LLM 量级（A），要么设计压力自带的任务
（如部分可观测推理、信息瓶颈明确的任务）。这两者都已
超出当前研究方案的预算边界——登记、不立项。

至此本备忘录所有路径均有判读，收口。实验线的最终遗产：
坍缩三条件对照（训练产物 + 目标鲁棒）本身是一个可发表的
机制发现，并入 sequel 素材库。
