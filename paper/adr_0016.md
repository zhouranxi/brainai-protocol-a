## 一、先把谱系摆清楚：R1 不是"优雅性论文"，它是止损后长出来的

这一点必须先说清楚，否则下一步会跑偏。

| 阶段 | 判定 | 依据 |
|---|---|---|
| Phase 0（原命题 C2） | **NO-GO** | 几何量与 test acc 全样本 r=−0.48，方向相反；簇内相关性崩塌（ADR-0006） |
| R1（受控再分析） | **GO，但是降级的 GO** | 换成"几何标记能否作为 OOD 预测量"这个**不同的问题**后，结论成立（ADR-0010） |

ADR-0006 明确写了"任务三（优雅性度量作为泛化预测量）**停止**"，并禁止"在同一框架内换指标"
（那是 p-hacking）。R1 之所以合法，是因为它**换了因变量**（从"优雅性↔同分布性能"换成
"几何标记↔OOD 迁移"），不是换了指标。

**所以 R1 是一篇"方法论审计论文"，不是原始方案的兑现。** 原方案的三条命题现在状态是：

| 命题 | 状态 |
|---|---|
| C1 优雅性可被几何量操作化 | 部分成立（有信息量混淆） |
| C2 优雅性指标与泛化相关 | **不成立**（已止损） |
| C3 人工↔生物可比 | 搁置 |

**推论：R1 论文投完后，"优雅性"这条线没有可发的东西了。** 下一步必须换问题，不是换实验。

## 三、三个候选方向（按我的推荐排序）

### 候选 A ★推荐：方法学短文 ——「表征几何指标的测量学」

**这是 ADR-0006 明确指定的 D1 路线，也是三条候选里唯一"数据已经全部在手"的。**

**核心问题**：现在有 13+ 个几何指标被当成"表征质量"的候选，但没有一篇论文系统回答：
> 每个指标**测的是什么**？在什么条件下它退化成同义反复？什么时候它的符号会翻转？

**为什么这是真缺口**（不是我编的）：

1. **ADR-0002 记录的信息量混淆**是真实存在的陷阱，且被真实触发过一次。
2. **ADR-0014 发现的跨实现不一致**：自实现 GLUE 与官方实现下，`radius` 和 `utility`
   的 OOD 预测力符号**完全相反**（自实现 +0.376/−0.228，官方 −0.881/+0.840）。
   → **同一个指标，换个实现就换符号。** 这本身就是一个值得发表的测量学发现，
   而且它直接反驳了"这些指标是稳定的表征质量度量"的默认假设。
3. **ADR-0010 发现 `radius` 在两份官方数据间符号不稳定** —— 同一指标在两份数据上都不稳。
4. **Phase 0 发现"配方内去中心后指标不动"**（`local_smoothness` 残差 r=−0.079）→ 指标测的是
   配方整体效应，不是样本级质量。

**论文骨架**（短文，目标 6–8 页）：

| 节 | 内容 | 数据来源 |
|---|---|---|
| 1 | 问题：几何指标作为"表征质量"度量的三个未检验前提 | — |
| 2 | 测量学框架：每个指标测什么、什么条件下退化 | ADR-0002 框架 |
| 3 | 受控退化实验：输入信息量恒定 vs 变化，两组对照 | 42 模型配方数据 |
| 4 | **跨实现一致性检验**：同一模型、同一指标、不同实现 | 48 组自建 + 官方 224 模型 |
| 5 | 符号稳定性地图：13 个指标 × 5 类偏移 × 2 个实现 | 全部已有数据 |
| 6 | 实践指南：什么样的几何主张可以站住 | 汇总 |
| 附 | 工具包（已开源） | — |

**杀手锏**：第 4 节。**这是唯一能"一文打尽"的实验设计** —— 我们手上有
「官方实现 + 官方数据」和「自实现 + 自建数据」两个正交组合，可以直接检验
"指标的预测力是模型的性质还是实现的性质"。这个问题目前没人系统回答过。

**产出形态**：1 篇方法学短文 + 已有工具包（已开源，CI 已就绪，133 条断言自动校验）
**风险**：低。数据全部在手，只需重新组织分析 + 写作。
**周期**：数据准备 1 周（主要是补几组交叉表）+ 写作 2 周。

### 候选 B：任务四 —— 细粒度干预与可解释性工具

**这是 ADR-0006 指定的 D3 路线，也是原方案里唯一"没被否证"的任务。**

**核心问题**：能否对表征流形做**定向干预**，并测量其因果后果？

**为什么现在做是对的**：
- Phase 0 已经证明**只读测量**（相关性）这条路走不通（C2 NO-GO）
- 但**干预**是另一类证据：它不依赖"指标与性能相关"，而依赖"改指标能改性能"
- ADR-0006 的 C1 判定"部分成立"意味着几何量确实**可算、可测、可干预**——
  只是不能作为被动预测量

**关键实验**：
1. 在**固定 ID 准确率的子集**上，对表征子空间做定向扰动（如沿 `D_eff` 下降方向）
2. 测量 OOD 性能的**因果**变化
3. 与 R1 的观察性结论对照：**观察性说"相关"，干预说"因果"**

**这条线的价值主张很强**：R1 说"几何标记在特定条件下能预测 OOD"，
任务四能说"**而且你可以通过操纵它来改变 OOD**"——从相关性工具升级为干预工具。

**产出形态**：1 篇可解释性/干预工具论文
**风险**：中高。干预实验的效应量未知，可能做出来是 null。且需要新训练（干预实验通常要
按干预条件重新训练或微调，成本高于纯推理期测量）。
**周期**：4–6 周，GPU 成本约 20–30 小时。
**前置**：需要先做一批"干预强度 → 性能"的预实验确认效应量存在，否则容易白烧 GPU。
建议**先用 2–3 天做效应量探测**，再决定是否全面展开。

### 候选 C：C3 —— 人工流形与生物流形可比

**原方案最核心、也最被搁置的一条。**

**核心问题**：人工模型的表征几何性质，与生物神经元的几何性质，能否在同一套度量下比较？

**为什么现在还不该做**：
- ADR-0003 明确：任务二（脑科学数据基础）**任何情况下都不在 Phase 0 启动**
- C3 依赖任务二。PRD 原文："C3 Phase 0 不做"
- 需要的神经数据集（Allen Institute V1/V2、CRCNS）与 fMRI 电生理都有获取与许可门槛
- **最关键**：ADR-0006 已经证明"优雅性指标与性能无关"。如果 C3 成立，跨物种比较的是什么？
  一个与性能无关的量？**立论基础已经不牢了。**

**我的判断**：**现在做 C3 是最差的选择。** 它是整个方案里最贵、最慢、且前提已被削弱的一条。
除非有别的团队已经在做生物侧、你能拿到现成的神经数据，否则不值得。

## 附录：候选 A 核心实验的可行性实测（2026-11-02 已跑通）

在定稿推荐之前，我先把这个实验实际跑了一遍，确认它不只是概念上成立。
**结果比 ADR-0014 记录的更精确，也更有发表价值。**

### 实验设计
同一 GLUE 指标，跨「实现」×「数据源」三个格子：官方实现 + 官方 224 模型 release、
官方实现 + 官方 80 模型 release、自实现（`glue_impl.py`）+ 自建 48 模型。
三者统一用 ID 受控（band 围绕 `acc_test` 均值）+ 架构残差化。

### 结果（Pearson r）

| 指标 | 官方224(官方实现) | 官方80(官方实现) | 自建48(自实现) | 模式 |
|---|---|---|---|---|
| `dimension` | **+0.925** (n=106) | **+0.737** (n=25) | **+0.919** (n=32) | **跨实现跨数据源全一致** |
| `radius` | **−0.584** (n=106) | **+0.153** (n=25) | **+0.602** (n=32) | **符号随实现/数据源翻转** |
| `utility` | **+0.901** (n=106) | **+0.808** (n=25) | **+0.342** (n=32) | 官方两格一致，自实现变弱 |

### band 敏感性（band = 1/2/3/5 pp）

| 指标 | 官方224 | 官方80 | 自建48 |
|---|---|---|---|
| `dimension` | +0.925 / +0.911 / +0.906 / +0.904 | +0.737 / +0.713 / +0.751 / +0.776 | +0.919 / +0.910 / +0.908 / +0.914 |
| `radius` | −0.584 / −0.796 / −0.790 / −0.786 | +0.153 / +0.025 / −0.163 / −0.221 | +0.602 / +0.527 / +0.386 / +0.407 |
| `utility` | +0.901 / +0.886 / +0.879 / +0.877 | +0.808 / +0.729 / +0.726 / +0.761 | +0.342 / −0.064 / −0.229 / −0.214 |

### 三点结论

1. **`radius` 的符号翻转不是带宽假象** —— 官方224 上在所有 band 下都是负（−0.58 ~ −0.80），
   官方80 上从 +0.15 漂到 −0.22，自建上稳定为正（+0.39 ~ +0.60）。
   **同一指标，换个实现就换符号，且这不是小样本噪声。**
   这直接支持一个尚未被系统陈述的命题：**GLUE 的 `radius` 不是一个稳定的 OOD 预测量，
   它的符号是实现细节的函数。**

2. **`utility` 的跨实现分歧是"量级坍塌"而非符号翻转** —— 官方 +0.90/+0.81，自实现 +0.34
   且在宽 band 下转负（−0.23）。即：自实现与官方**测的可能不是同一个量**。
   这比单纯的符号翻转更有意思，因为它指向"实现等价性"这个更深的问题。

3. **`dimension` 是唯一三格全一致的指标**（+0.74 ~ +0.93），
   且在官方数据上带宽不敏感（0.925→0.904，变化 <0.03）。
   → 它是目前唯一可以推荐的 GLUE 指标 —— 而这个结论**没有任何一篇现有论文给出过**。

### 这如何改变候选 A 的定位

原本我以为候选 A 是"整理已有发现"。实测之后，它变成了一篇有**独立新发现**的论文：

> **GLUE 三指标的 OOD 预测力，按跨实现稳定性分为三档：
> 稳健（dimension）、符号不稳定（radius）、实现依赖（utility）。
> 现有文献把三者并列为"任务相关的几何标记"，但只有第一个经得起跨实现检验。**

这个结论**不能**从 R1 论文里推出来（R1 只用了官方实现 + 官方数据），
也不能从 Phase 0 推出来（Phase 0 没有 GLUE）。**它是新的。**

## 附录二：候选 B 效应量探测结果（2026-11-04，已完成）

按本 ADR 第三节候选 B 的前置建议（"先用 2–3 天做效应量探测"），
当晚在学校 4×3090 服务器上完成（GPU 1/2/3 分片，约 30 分钟墙钟时间，
脚本 `code/intervene_effect_probe.py`，完整报告 `results/intervene_probe_report.md`）。

### 设计摘要

8 个 ID 受控 resnet18（id_acc 0.851–0.884）× 12 条件（base / flatten×4 /
sharpen×4 / placebo×3），全部**推理期**操作：算子只在 ID 特征上拟合，
同一映射作用于 OOD 特征。测扰动后 GLUE 三指标 + ID acc + c100 probe + c10c acc。

### 结果（8 模型均值）

| 条件 | D_eff | id_acc | c100 probe | c10c |
|---|---|---|---|---|
| base | 1.30 | 0.8712 | 0.1890 | 0.6240 |
| flatten 4.0 | 12.96 | 0.8481 | 0.0830 | 0.5991 |
| placebo 4.0 | 1.31 | 0.8711 | 0.1890 | 0.6239 |

- 操纵检查：flatten 强度 → D_eff 逐模型 r ≥ 0.992（8/8），D_eff 提升 10 倍
- 安慰剂检查：同等噪声功率的单方向扰动**几乎零效应**（Δ 全部 ≤0.03 D / 0.0003 c100）
- 核心发现：**因果效应与观察相关反号**。观察性 D_eff↔c100 为 r≈+0.92；
  干预下 D_eff 升 10 倍，c100 单调降 −56%（相对），逐模型斜率 **8/8 全负**。
  ID acc 在 α≤2 时变化 <0.5pp（功能保持）。

### 判定：GO（带限定）

按 ADR-0003 闸门标准（管线通、操纵/安慰剂过、效应量单调且跨模型同号），
候选 B 正式立项展开。**限定**：当前证据证明的是"flatten 算子族的因果效应为负"，
即观察相关不是因果收益、D_eff 是配方驱动的伴随标记（与测量论文结论互恰）。
全面展开需补**不加噪声的几何算子**（子空间缩放/流形旋转/插值），
以分离"几何本身"与"噪声注入"两条因果路径——这是下一篇论文的核心实验。

1. 同样把 D_eff 推高 ~10：噪声注入 c100 崩 −0.106，零噪声白化 c100 反升 +0.020。

2. 几何通路存在且与观察同向（D↓伤、白化式 D↑微益），但幅度仅为观察斜率的

3. **D_eff 的三重身份定论：真实描述统计量 + 弱因果通路（同向）+ 强配方标记。**
   干预论文的核心命题由此成形：操纵几何 ≠ 复制配方，观察相关不可反演为干预处方。

### 修订一（2026-11-04 23:50，仍在任何 E5 数据产生前）：假设结构细化

写 E5b 脚本时复查 E3 代码发现：c100 读数

- **H-cond（探针条件数，新增）**：白化改善线性探针的优化条件
  （协方差谱压平 → SGD 更易收敛）→ 预测：收益随剂量**单调**增长

- H-geom（原）：收益来自形成期的几何信息重组 → 预测单调 + 需 formation。
- H-reg（原）：随机正则副产品 → 预测平坦。

1. **平坦** → H-reg，论文结论原样存活；
2. **单调且 ID-formation-only 读数无收益、纯探针空间变换复现全部收益**

## 附录十六：P4 预注册——训练期几何 forcing（2026-11-06，跑前写下）

### 动机与空缺

两篇论文的证据链：(1) 观察相关 r(D_eff, c100)=+0.97 跨实现跨架构稳定，但它是
**配方标记**（测量学论文：18/24 家族符号随偏移类型翻转）；(2) 推理期几何干预
只有观察斜率的 ~6%（E1/E5 系列噪声分离后）；(3) E3「训练期白化」是白化**已训
特征**再训 fc 头（trunk 冻结），本质是表征形成**之后**的工序，不是形成期干预。

**P4 补上真正的形成期干预**：训练进行中直接 forcing 几何，让网络把 D_eff
训到目标值——「geometry is a label, not a knob」的终审判决。
- 若 forcing 后 c100 跟上观察斜率（把 D_eff 从 0.9 推到 2.1，c100 应到 ~0.28）
  ⇒ geometry 是 knob，前两篇结论被推翻/限定；
- 若 c100 不跟（预期）⇒ 形成期也不能把标记变成旋钮，三条证据闭合。

### 干预算子（全部零噪声、确定性，训练中每步施加）

按 E5 的结论「反号效应全部来自噪声注入」，P4 只用零噪声谱算子，在
**penultimate 特征层**施加，loss = CE + λ·L_forcing：

- **F-whiten（类内白化 forcing）**：L = Σ_k ||C_k − I·tr(C_k)/d||_F² / d，
  C_k 为类 k 特征协方差。把类内谱拉平 ⇒ D_eff↑（与推理期 recolor(0) 同方向的
  形成期版本）。
- **F-disperse（谱均衡 forcing）**：L = (log tr(C) − H(log λ))² 的负熵形式，
  直接最大化谱熵 ⇒ D_eff↑。与 F-whiten 互为稳健性检查。
- **F-concentrate（反向 forcing，阴性对照）**：L = −Σ λ_k² 归一化（把谱压到
  top-1）⇒ D_eff↓。若 D↓ 而 c100 不动/反升，则「D↔OOD」连形成期因果都不存在。

（λ 逐条件扫描 {0.01, 0.1, 1.0}；λ 上限由「ID acc 下降 ≤2pp」的功能保持
约束决定，超过记功能破坏，不进主判定。）

**λ 阶梯修订（2026-11-06 冒烟后、200ep pilot 启动前）**：单 batch 梯度实测
（resnet18，CIFAR-10 首 batch）：|g_CE|=20.4，|g_whiten|=0.249（λ=0.01 时
forcing 梯度占比 ~0.1%）、|g_disperse|=|g_concentrate|=6.0、|g_placebo|=43.5。
按「forcing 梯度 ≈ 1–10% CE 梯度」的目标带，λ 阶梯修订为
**whiten {0.1, 1.0}、disperse/concentrate {0.005, 0.05}、placebo {0.001, 0.01}**
（各算子梯度量级差 ~25 倍，统一 λ 不公平）。冒烟的 id=0.10 经与 train_grid
history 对照（lr=1.0 普通训练前 3ep 本来就是 0.10，ep20 才 0.36）确认为
学习率早期震荡，非 forcing 破坏——功能保持判定只能在 200ep 端点做。

### 条件矩阵（pilot → 全量两阶段）

- **Pilot（先行，~2 GPU·h）**：2 配方 × 4 算子 × λ=0.1 × 1 种子，200 epoch
  全程 forcing：
  - `lr1.0_wd5e-05_s0`（GLUE D=0.89 / d_ent=9.35, c100=0.120，网格最低点——forcing 主角）
  - `lr0.125_wd0.0001_s0`（GLUE D=1.79, c100=0.273，网格最高点——对照）
  **D 双口径注记（2026-11-06 跑前核对）**：GLUE dimension（0.89/1.79，E1 锚点）
  与 pooled 谱熵 d_ent（9.35，E5d 同构造实测一致 9.35）是两个口径；P4-1 操纵
  检查的「移动 ≥0.3」作用于 **d_ent 口径**（训练中可监控），端点判定仍以
  GLUE dimension 为准。两者各自与自身 base 比。
  判定 pilot GO：操纵检查过（d_ent 实际移动 ≥0.3）且 ID acc 保持（≥base−2pp）。
- **全量（pilot GO 后）**：8 配方（E1 同清单）× 3 算子 × 3 λ × 3 种子，
  200 epoch；对照臂 = 同配方同种子 base（ckpt_grid 已有 48 个 resnet18
  可复用同种子配对）。

### 预注册判据（跑前写下）

- **P4-1（操纵检查）**：F-whiten/F-disperse 使 D_eff 移动 ≥0.3
  （d_ent 口径 + GLUE dimension 双口径都要动），F-concentrate 使 D_eff
  下降 ≥0.2。失败 ⇒ forcing 不构成干预，P4 停。
- **P4-2（主判定，knob 判决）**：把 8 配方×3 种子的 (ΔD, Δc100) 汇成
  forcing 斜率 s_forcing = Δc100/ΔD，与观察斜率 s_obs=+0.137 对比：
  - **knob**：s_forcing ≥ 0.5·s_obs 且同号率 ≥6/8 ⇒ 形成期几何因果存在，
    前两篇结论需限定；
  - **label（预期）**：s_forcing ≤ 0.2·s_obs ⇒ 形成期 forcing 也不能把
    观察相关变成可用因果通路，三重身份定论闭合；
  - **中间带**（0.2–0.5）：如实报告并分析逐模型异质性（按 base D 分层）。
- **P4-3（阴性对照）**：F-concentrate 下 D↓ 而 Δc100 ≥ −0.01（即不随 D
  同向下降）⇒ 强证据「D 与 OOD 在形成期也无因果联系」。
- **P4-4（噪声对照）**：所有算子零噪声；同时跑 placebo loss（λ·||W||²
  随机方向正则，同 λ）各 1 条件，其 Δc100 应 ≈0。若 placebo 也大幅移动
  c100 ⇒ forcing 效应可能是正则化伪效应，全部结论降级。

## 附录十八：P4 b2 首发全线崩溃 → 根因修复 → b2v2 重发（2026-11-06）

### 事故

b2 首发三卡，disperse@0.005 与 concentrate@0.005 在 ep20 即 test=0.1000、
d_ent~NaN，与 pilot 批 λ=0.1 的崩溃完全一致——**λ 缩小 20 倍无效** ⇒ 排除
剂量假说，指向 loss 实现缺陷。GPU0 的 disperse 链当场终止，GPU2 的
concentrate 空转 8 分钟后手动终止；placebo@0.01（GPU3）不受影响继续跑
（线性投影路径，无特征分解）。

### 根因

`forcing_loss` 的 disperse/concentrate 分支把 8 步幂迭代
（C@V、除以范数、QR）**整体挂进 autograd 计算图**。特征值简并时特征向量
对 C 的梯度按 1/eigengap 发散，一步 NaN 即永久毒化权重（输出恒为均匀
softmax ⇒ 精确 0.10；eigh 全程不收敛 ⇒ d_ent 全 NaN）。whiten（纯二次型）
与 placebo（线性投影）无该结构所以健康。测试集上方向单元测试通过——
它只验前向数值，验不出反向图爆炸。

### 修复（v2，已入 train_forcing_p4.py）

1. 特征向量求解移出计算图：`no_grad + float64 + CPU eigh`（数值稳健），
   取 top-K 特征向量快照 V；
2. 梯度只走 Rayleigh 商 r_k = v_kᵀCv_k（v 固定 ⇒ ∂r/∂C = vvᵀ 有界），
   精确特征向量处 r_k = λ_k，谱语义与 v1 完全一致；
3. 训练环护栏：fl 为 None/NaN/Inf 时该 batch 退化纯 CE 并计数 n_bad_fl，
   毒化梯度绝不进 opt.step()。

服务器验证：4 算子 × {尖谱, 平谱} 前向有限、反向梯度全有限
（|g|max ~1e-4–1e-3）；NaN 输入触发护栏路径。梯度模长重测：
whiten 0.254 / dis-con 5.21 / placebo 51.2（CE 19.3）——与 v1 量级一致，
**λ 阶梯维持原修订不变**。

### 归因证据（b2v2 早期读数）

- **disperse@λ=0.1 重发后 ep20 test=0.396 → ep60 0.688**（v1 同剂量
  20ep 永久 0.10）⇒ v1 崩溃确证为 NaN 缺陷而非剂量；λ=0.1 在修复后
  可用，pilot 批的 disperse 读数作废，以 b2v2 为准。
- concentrate@0.005 ep20 短暂 0.10（lr=1.0 早期震荡）后 ep40 恢复

- 毒化 run 目录改名 *.poisoned_v1 留存取证，不复用。

### b2v2 布局（3 卡并行，每卡串两配置）

- GPU0：disperse@0.005 → whiten@1.0
- GPU2：concentrate@0.005 → concentrate@0.05

  原样数据上判「线性」，在排除异常点后判「幂律」。按预注册

  降级条款适用），正式判定取 **√ 形幂律**，异常点处置与

### R2（幂律指数）：b = 0.502（95% 待 bootstrap，点估计恰为 1/2）

b 的点估计 0.502 落在 √ 形（b=1/2）上。若 b 的 CI 完全 <1 ⇒
「强凹」成立——**点估计 0.5 远离 1，强凹无疑**。

### R3（饱和起点）：断崖式而非渐近

局部斜率序列（hi 系，排除异常点）：
**14.4% → 5.7% → 1.9% s_obs**。
λ 1→3 的增量斜率 0.00031 = **1.9% s_obs**——平台不是渐近贴零，
而是三步内衰减 7 倍的断崖。**「推得越远，每单位 D 换到的
c100 越少」在剂量轴上有具体形状：√ 起步，λ≥1 后深度饱和。**

### 与 P4 判决的关系（不动摇，反而强化）

- 全量批 label 判决（斜率 ≤0.2·s_obs）：剂量扫描的**所有点
  斜率 ≤17.3%**，无一越阈 ✓；

  断崖饱和**的完整刻画；

### 方法论注记

1. **5 点 + AICc 的判据设计教训**：n=5 时 AICc 的参数惩罚
   （k=2 vs 3 差 1 个参数、除数 n−k−1）会系统性偏向简单模型，
   逐配方的「线性胜出」是过约束假象。形态判定在 n≥4 且去掉
   带内噪声点后才可靠。
2. **placebo 带宽是数据清洁工具**：λ=0.03/0.3 两点 Δc 落在
   ±0.022 带内——它们的信息量与 placebo 等价，拟合时应降权
   或剔除（附录十九的降级条款在剂量轴上的直接应用）。
3. **lo 系的「无响应」本身是结果**：低 D 基线（9.35）模型对
   whiten forcing 的 c100 响应全部在噪声带内——几何响应面
   存在**配方依赖的量程差异**，hi 基线（18.88）有可测响应，
   lo 基线没有。
