## 一、先把谱系摆清楚：R1 不是"优雅性论文"，它是止损后长出来的

这一点必须先说清楚，否则下一步会跑偏。

| 阶段 | 判定 | 依据 |
|---|---|---|
| Phase 0（原命题 C2） | **NO-GO** | 几何量与 test acc 全样本 r=−0.48，方向相反；簇内相关性崩塌（ADR-0006） |
| R1（受控再分析） | **GO，但是降级的 GO** | 换成"几何标记能否作为 OOD 预测量"这个**不同的问题**后，结论成立（ADR-0010） |

ADR-0006 明确写了"任务三（优雅性度量作为泛化预测量）**停止**"，并禁止"在同一框架内换指标"
（那是 p-hacking）。R1 之所以合法，是因为它**换了因变量**（从"优雅性↔同分布性能"换成
"几何标记↔OOD 迁移"），不是换了指标。

**所以 R1 是一篇"方法论审计论文"，不是原始方案的兑现。** 原方案的三条命题现在状态是：

| 命题 | 状态 |
|---|---|
| C1 优雅性可被几何量操作化 | 部分成立（有信息量混淆） |
| C2 优雅性指标与泛化相关 | **不成立**（已止损） |
| C3 人工↔生物可比 | 搁置 |

**推论：R1 论文投完后，"优雅性"这条线没有可发的东西了。** 下一步必须换问题，不是换实验。

## 三、三个候选方向（按我的推荐排序）

### 候选 A ★推荐：方法学短文 ——「表征几何指标的测量学」

**这是 ADR-0006 明确指定的 D1 路线，也是三条候选里唯一"数据已经全部在手"的。**

**核心问题**：现在有 13+ 个几何指标被当成"表征质量"的候选，但没有一篇论文系统回答：
> 每个指标**测的是什么**？在什么条件下它退化成同义反复？什么时候它的符号会翻转？

**为什么这是真缺口**（不是我编的）：

1. **ADR-0002 记录的信息量混淆**是真实存在的陷阱，且被真实触发过一次。
2. **ADR-0014 发现的跨实现不一致**：自实现 GLUE 与官方实现下，`radius` 和 `utility`
   的 OOD 预测力符号**完全相反**（自实现 +0.376/−0.228，官方 −0.881/+0.840）。
   → **同一个指标，换个实现就换符号。** 这本身就是一个值得发表的测量学发现，
   而且它直接反驳了"这些指标是稳定的表征质量度量"的默认假设。
3. **ADR-0010 发现 `radius` 在两份官方数据间符号不稳定** —— 同一指标在两份数据上都不稳。
4. **Phase 0 发现"配方内去中心后指标不动"**（`local_smoothness` 残差 r=−0.079）→ 指标测的是
   配方整体效应，不是样本级质量。

**论文骨架**（短文，目标 6–8 页）：

| 节 | 内容 | 数据来源 |
|---|---|---|
| 1 | 问题：几何指标作为"表征质量"度量的三个未检验前提 | — |
| 2 | 测量学框架：每个指标测什么、什么条件下退化 | ADR-0002 框架 |
| 3 | 受控退化实验：输入信息量恒定 vs 变化，两组对照 | 42 模型配方数据 |
| 4 | **跨实现一致性检验**：同一模型、同一指标、不同实现 | 48 组自建 + 官方 224 模型 |
| 5 | 符号稳定性地图：13 个指标 × 5 类偏移 × 2 个实现 | 全部已有数据 |
| 6 | 实践指南：什么样的几何主张可以站住 | 汇总 |
| 附 | 工具包（已开源） | — |

**杀手锏**：第 4 节。**这是唯一能"一文打尽"的实验设计** —— 我们手上有
「官方实现 + 官方数据」和「自实现 + 自建数据」两个正交组合，可以直接检验
"指标的预测力是模型的性质还是实现的性质"。这个问题目前没人系统回答过。

**产出形态**：1 篇方法学短文 + 已有工具包（已开源，CI 已就绪，133 条断言自动校验）
**风险**：低。数据全部在手，只需重新组织分析 + 写作。
**周期**：数据准备 1 周（主要是补几组交叉表）+ 写作 2 周。

### 候选 B：任务四 —— 细粒度干预与可解释性工具

**这是 ADR-0006 指定的 D3 路线，也是原方案里唯一"没被否证"的任务。**

**核心问题**：能否对表征流形做**定向干预**，并测量其因果后果？

**为什么现在做是对的**：
- Phase 0 已经证明**只读测量**（相关性）这条路走不通（C2 NO-GO）
- 但**干预**是另一类证据：它不依赖"指标与性能相关"，而依赖"改指标能改性能"
- ADR-0006 的 C1 判定"部分成立"意味着几何量确实**可算、可测、可干预**——
  只是不能作为被动预测量

**关键实验**：
1. 在**固定 ID 准确率的子集**上，对表征子空间做定向扰动（如沿 `D_eff` 下降方向）
2. 测量 OOD 性能的**因果**变化
3. 与 R1 的观察性结论对照：**观察性说"相关"，干预说"因果"**

**这条线的价值主张很强**：R1 说"几何标记在特定条件下能预测 OOD"，
任务四能说"**而且你可以通过操纵它来改变 OOD**"——从相关性工具升级为干预工具。

**产出形态**：1 篇可解释性/干预工具论文
**风险**：中高。干预实验的效应量未知，可能做出来是 null。且需要新训练（干预实验通常要
按干预条件重新训练或微调，成本高于纯推理期测量）。
**周期**：4–6 周，GPU 成本约 20–30 小时。
**前置**：需要先做一批"干预强度 → 性能"的预实验确认效应量存在，否则容易白烧 GPU。
建议**先用 2–3 天做效应量探测**，再决定是否全面展开。

### 候选 C：C3 —— 人工流形与生物流形可比

**原方案最核心、也最被搁置的一条。**

**核心问题**：人工模型的表征几何性质，与生物神经元的几何性质，能否在同一套度量下比较？

**为什么现在还不该做**：
- ADR-0003 明确：任务二（脑科学数据基础）**任何情况下都不在 Phase 0 启动**
- C3 依赖任务二。PRD 原文："C3 Phase 0 不做"
- 需要的神经数据集（Allen Institute V1/V2、CRCNS）与 fMRI 电生理都有获取与许可门槛
- **最关键**：ADR-0006 已经证明"优雅性指标与性能无关"。如果 C3 成立，跨物种比较的是什么？
  一个与性能无关的量？**立论基础已经不牢了。**

**我的判断**：**现在做 C3 是最差的选择。** 它是整个方案里最贵、最慢、且前提已被削弱的一条。
除非有别的团队已经在做生物侧、你能拿到现成的神经数据，否则不值得。

## 附录：候选 A 核心实验的可行性实测（2026-11-02 已跑通）

在定稿推荐之前，我先把这个实验实际跑了一遍，确认它不只是概念上成立。
**结果比 ADR-0014 记录的更精确，也更有发表价值。**

### 实验设计
同一 GLUE 指标，跨「实现」×「数据源」三个格子：官方实现 + 官方 224 模型 release、
官方实现 + 官方 80 模型 release、自实现（`glue_impl.py`）+ 自建 48 模型。
三者统一用 ID 受控（band 围绕 `acc_test` 均值）+ 架构残差化。

### 结果（Pearson r）

| 指标 | 官方224(官方实现) | 官方80(官方实现) | 自建48(自实现) | 模式 |
|---|---|---|---|---|
| `dimension` | **+0.925** (n=106) | **+0.737** (n=25) | **+0.919** (n=32) | **跨实现跨数据源全一致** |
| `radius` | **−0.584** (n=106) | **+0.153** (n=25) | **+0.602** (n=32) | **符号随实现/数据源翻转** |
| `utility` | **+0.901** (n=106) | **+0.808** (n=25) | **+0.342** (n=32) | 官方两格一致，自实现变弱 |

### band 敏感性（band = 1/2/3/5 pp）

| 指标 | 官方224 | 官方80 | 自建48 |
|---|---|---|---|
| `dimension` | +0.925 / +0.911 / +0.906 / +0.904 | +0.737 / +0.713 / +0.751 / +0.776 | +0.919 / +0.910 / +0.908 / +0.914 |
| `radius` | −0.584 / −0.796 / −0.790 / −0.786 | +0.153 / +0.025 / −0.163 / −0.221 | +0.602 / +0.527 / +0.386 / +0.407 |
| `utility` | +0.901 / +0.886 / +0.879 / +0.877 | +0.808 / +0.729 / +0.726 / +0.761 | +0.342 / −0.064 / −0.229 / −0.214 |

### 三点结论

1. **`radius` 的符号翻转不是带宽假象** —— 官方224 上在所有 band 下都是负（−0.58 ~ −0.80），
   官方80 上从 +0.15 漂到 −0.22，自建上稳定为正（+0.39 ~ +0.60）。
   **同一指标，换个实现就换符号，且这不是小样本噪声。**
   这直接支持一个尚未被系统陈述的命题：**GLUE 的 `radius` 不是一个稳定的 OOD 预测量，
   它的符号是实现细节的函数。**

2. **`utility` 的跨实现分歧是"量级坍塌"而非符号翻转** —— 官方 +0.90/+0.81，自实现 +0.34
   且在宽 band 下转负（−0.23）。即：自实现与官方**测的可能不是同一个量**。
   这比单纯的符号翻转更有意思，因为它指向"实现等价性"这个更深的问题。

3. **`dimension` 是唯一三格全一致的指标**（+0.74 ~ +0.93），
   且在官方数据上带宽不敏感（0.925→0.904，变化 <0.03）。
   → 它是目前唯一可以推荐的 GLUE 指标 —— 而这个结论**没有任何一篇现有论文给出过**。

### 这如何改变候选 A 的定位

原本我以为候选 A 是"整理已有发现"。实测之后，它变成了一篇有**独立新发现**的论文：

> **GLUE 三指标的 OOD 预测力，按跨实现稳定性分为三档：
> 稳健（dimension）、符号不稳定（radius）、实现依赖（utility）。
> 现有文献把三者并列为"任务相关的几何标记"，但只有第一个经得起跨实现检验。**

这个结论**不能**从 R1 论文里推出来（R1 只用了官方实现 + 官方数据），
也不能从 Phase 0 推出来（Phase 0 没有 GLUE）。**它是新的。**

## 附录二：候选 B 效应量探测结果（2026-11-04，已完成）

按本 ADR 第三节候选 B 的前置建议（"先用 2–3 天做效应量探测"），
当晚在学校 4×3090 服务器上完成（GPU 1/2/3 分片，约 30 分钟墙钟时间，
脚本 `code/intervene_effect_probe.py`，完整报告 `results/intervene_probe_report.md`）。

### 设计摘要

8 个 ID 受控 resnet18（id_acc 0.851–0.884）× 12 条件（base / flatten×4 /
sharpen×4 / placebo×3），全部**推理期**操作：算子只在 ID 特征上拟合，
同一映射作用于 OOD 特征。测扰动后 GLUE 三指标 + ID acc + c100 probe + c10c acc。

### 结果（8 模型均值）

| 条件 | D_eff | id_acc | c100 probe | c10c |
|---|---|---|---|---|
| base | 1.30 | 0.8712 | 0.1890 | 0.6240 |
| flatten 4.0 | 12.96 | 0.8481 | 0.0830 | 0.5991 |
| placebo 4.0 | 1.31 | 0.8711 | 0.1890 | 0.6239 |

- 操纵检查：flatten 强度 → D_eff 逐模型 r ≥ 0.992（8/8），D_eff 提升 10 倍
- 安慰剂检查：同等噪声功率的单方向扰动**几乎零效应**（Δ 全部 ≤0.03 D / 0.0003 c100）
- 核心发现：**因果效应与观察相关反号**。观察性 D_eff↔c100 为 r≈+0.92；
  干预下 D_eff 升 10 倍，c100 单调降 −56%（相对），逐模型斜率 **8/8 全负**。
  ID acc 在 α≤2 时变化 <0.5pp（功能保持）。

### 判定：GO（带限定）

按 ADR-0003 闸门标准（管线通、操纵/安慰剂过、效应量单调且跨模型同号），
候选 B 正式立项展开。**限定**：当前证据证明的是"flatten 算子族的因果效应为负"，
即观察相关不是因果收益、D_eff 是配方驱动的伴随标记（与测量论文结论互恰）。
全面展开需补**不加噪声的几何算子**（子空间缩放/流形旋转/插值），
以分离"几何本身"与"噪声注入"两条因果路径——这是下一篇论文的核心实验。

1. 同样把 D_eff 推高 ~10：噪声注入 c100 崩 −0.106，零噪声白化 c100 反升 +0.020。

2. 几何通路存在且与观察同向（D↓伤、白化式 D↑微益），但幅度仅为观察斜率的

3. **D_eff 的三重身份定论：真实描述统计量 + 弱因果通路（同向）+ 强配方标记。**
   干预论文的核心命题由此成形：操纵几何 ≠ 复制配方，观察相关不可反演为干预处方。

### 修订一（2026-11-04 23:50，仍在任何 E5 数据产生前）：假设结构细化

写 E5b 脚本时复查 E3 代码发现：c100 读数

- **H-cond（探针条件数，新增）**：白化改善线性探针的优化条件
  （协方差谱压平 → SGD 更易收敛）→ 预测：收益随剂量**单调**增长

- H-geom（原）：收益来自形成期的几何信息重组 → 预测单调 + 需 formation。
- H-reg（原）：随机正则副产品 → 预测平坦。

1. **平坦** → H-reg，论文结论原样存活；
2. **单调且 ID-formation-only 读数无收益、纯探针空间变换复现全部收益**

## 附录十四：E5e——天花板/饱和 conjecture 补验（2026-11-05，已完成）

### 动机

因果论文 §E3 stratification 段留下两个明确标注"未检验"的 conjecture：
①**算子饱和**——lr1.0 模型白化无 headroom，收益消失（主角：lr1.0_wd5e-05_s0，
E3 收益 −0.03pp，D_eff 全网格最小）；②**高-D headroom**——高 D_eff 模型

### 设计

把 E5c 式直接测量（探针空间谱条件数 + 40-epoch 共享协议训练曲线，
orig vs γ=0 dose-whitened）从 3 个 E5b 模型扩展到**全部 8 个 E3 配对模型**
（3 个重叠 E5c，构成种子钉定的复现校验）。新脚本

服务器 GPU0 约 30 分钟，可断点续跑）+ `code/analyze_e5d_ceiling.py`。

### 结果（commit 本轮，runs/v2_e5d_ceiling/）

1. **饱和证实（锐化形式）**：负模型 lr1.0_wd5e-05_s0 原空间 in-rank 条件数
   **294**（其余 7 模型 10³–10⁹）——协方差**本来就近白化**，算子无可去除：
   白化仅改善 22×（其余中位 4.6×10³×）、可达损失不降（4.134→4.165，
   8 模型中 3 个不降之一，另两个是慢收敛 lr0.5 探针）、探针收益 +0.08pp
   （8 模型最小）。饱和是**表示的性质**（该配方训出的谱本就平），
   不是算子的性质。
2. **高-D headroom 被推翻**：D_eff 与白化收益**正相关**
   （Spearman ρ=+0.857, p=0.007；高-D 三模型均值 +3.5pp vs 其余 +0.9pp）。
   高-D 模型 headroom **更多**而非更少；收益缺席与配方锐度相关，
   与几何无关——与 §E3 剂量-反应裁决一致。
3. **复现校验**：与 E5c 的 18 个重叠条件，条件数 15/18 精确相等、
   18/18 在 1e-6 相对容差内（残差 3 例来自 BLAS 特征值末位），
   最终 acc 18/18 精确相等。
4. **数字修正**：论文 stratification 段 D_eff 0.89 → **0.87**（数据 0.8742；
   此前审计未覆盖该数字——第四轮补漏的又一漏网，现已加入断言）。
