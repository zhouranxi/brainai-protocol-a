## 一、这套协议解决什么问题

本研究程序（2026-11-05 至 11-21）在执行中发现并记录了四类系统性评估陷阱，每一条都烧掉了真实算力才换来判据。本白皮书把它们提炼为可复用的评估协议，适用于**表征几何 / 干预因果 / marker 排名**三类研究，并附全部实例。

| 陷阱 | 代价（真实案例） | 协议条款 |
|---|---|---|
| 测试架未校准即发射 | P18 三批全饱和（基线 97%/88%/96%），2.5 天作废 | §2 健康闸先行 |
| 探针增益误读为行为增益 | 主论文 14.7% 传导结论被全库复核推翻（12/12 零传导） | §3 三口径规范 |
| 无效批次被静默丢弃 | 两次训练崩溃、三次饱和批若丢弃则证据链断裂 | §4 无效批次一等公民 |
| 负结果无判据可落 | 早期负结果无法干净收口 | §5 预注册裁决 |

## 二、健康闸先行（任何测量前）

**规则**：在花任何算力之前，先用 ≥20 个样本试点确认测量仪能测到目标效应。

- **基线带判据**：目标效应量级的基线读数必须落在**可分辨区间**（本程序：20–85%）。基线 ≥85% = 天花板（P18 批 A，C0=97%，8 条件挤在 3pp 带宽内，任何差异都是 2–3 题翻转噪声）；基线 ≤20% = 地板。
- **校准样本 ≠ 批样本**：P18 批 B 的教训——20 题校准落在带内（0.80），但实际批混入更易题后基线漂到 0.88，超出上沿。**校准抽样的难度分布必须与正式批一致**，或直接用「难度分层 × 全桶」设计（批 C：纯 steps≥7 桶，实测 0.957 仍然饱和——说明该基准×模型组合整体不可用，换基准而非再调桶）。
- **测量噪声地板**：报告每个度量的 bootstrap σ（P21：σ/L 中位比 0.0032，信号/噪声 >300× 才继续）。
- **干预有效性闸**（干预研究特有）：瓶颈/forcing 的设计必须先验证「确实制造了前馈不足」（P16：三瓶颈 FF 健康闸全过——mask 0.75/width 0.93/data 0.83，证明瓶颈「难而不废」，否则 HFB−FF 零增益无法与瓶颈失效区分）。

## 三、三口径报告规范

**规则**：任何「表征干预的增益」结论必须同时报告三个口径，缺一不可。

| 口径 | 定义 | 防什么 |
|---|---|---|
| **ID 精度** | 干净测试集准确率 | 把行为代价藏起来（P12 失灵批：id 闸过线但 c10c 0.68–0.70，真实行为代价被 id 掩盖） |
| **腐蚀精度**（c10c/shift） | 分布外腐蚀均值 | 只看 id 得出「无害」假象（ADR-0021：E4 forcing 的 Δc100 响应在全库 114 checkpoint 确认为 probe-specific——12/12 剂量点 Δc100≥2pp 但 Δc10c 全在 ±0.5pp 噪声带） |
| **探针精度** | 线性探针读数 | 探针增益 ≠ 行为鲁棒性——whiten forcing / REC 横向 / recolor 三例证 + 全库扫描证明这是**系统性现象**，不是个例 |

**推论**：marker 相关（r(X, c100)）只证明「预测」不证明「因果」——ADR-0026 再证：谱代理（d_ent, r=+0.90）与非谱代理（L_knn, r=+0.93）都是 D_eff 信息家族成员（r(w/ D_eff)=0.83/0.91）；唯一通过独立性检验的是 GLUE utility（partial r(c100, U | D_eff) = −0.607）——**marker 独立性必须用偏相关检验，不能用边际相关**。

## 四、无效批次一等公民

**规则**：崩溃批、饱和批、判无效批**全部保留**在归档里，作为证据链的一部分。

- **实例账本**（全部在 Zenodo v2.0.0）：
  - N1/N1′（ADR-0019）：REC/HFB 训练崩溃 ×2 → 定位架构缺陷，最终引出「纯调制式反馈零增益」结论的必要前置；
  - P18 批 A/B（ADR-0023）：天花板批 ×2 → 「GSM8K×qwen3:8b 组合上正式裁决不可得」本身就是结论，且三批一致的描述性信号（token 效率 −22~31%）比一次「有效」批更有信息量；
  - A0（ADR-0024）：P1 方差响应三种子反向（ρ=−1.0）→ 用 2.7 GPU·h 否决了 63 GPU·h 的后续实验 A/B/C——**这是无效批的最高价值形态：最小成本买最明确否决**。
- **操作规范**：无效判读必须在 ADR 中**写明失效模式**（崩溃/饱和/方向反），后续批的 Go/No-Go 条款引用它作为先验。

## 五、预注册裁决（Go/No-Go 闸门）

**规则**：判据在**任何数据产生之前**冻结进 ADR，跑后不得改。

- **分层判据模板**（本程序 13 个 ADR 全部遵循）：
  1. 主判读（Go 判据，带数值门槛）；
  2. 保护分支（No-Go / 判无效的明确条款，含方向判据）；
  3. 健康闸（§二）作为前置，先于主判读执行；
  4. 触发条款（过线 → 下一个 ADR 编号与内容预声明）。
- **方向判据与幅度判据并重**：A0 的教训——P1 不只 FAIL，是**方向相反**（ρ=−1.0 vs 要求 ≥+0.8）。方向反转比幅度不足信息量大得多，预注册时必须写明期望方向。
- **1-D 扫描的共线性警戒**（ADR-0025 教训）：剂量轴上 r(S, c100)=0.99 是 λ 单调推高一切的假象，**不得外推为跨模型 marker 排名**——跨模型证据（F-a，n=68）才是有效证据。
- **并发写竞态**（工程条款）：多进程写同一 JSON 必须单链独占或加锁——ADR-0025 剂量轴两残留进程并发写同一输出文件，已按单链修复并写入规范。

## 六、算力经济学

**规则**：用小批买否决，不用大批赌通过。

| 决策点 | 本程序实践 | 省/花 |
|---|---|---|
| 门控探针先于架构批 | A0：2.7 GPU·h 否决实验 A/B/C | **省 63 GPU·h + 数月** |
| 零训练批先于训练批 | P19/P21/P22 全部在既有 checkpoint 上测（~1 GPU·h/批） | 相比重训 ~40 GPU·h/批，省 40× |
| 现象学前置于立项 | P21 压缩批：第零轮先证谱代理是克隆，前置批只测非谱代理 | 直接砍掉一半设计空间 |
| 分桶校准先于全批 | P18 批 C 纯 steps≥7 桶（校准即批） | 相比再发一批混合桶，省 ~4h |

**通用排序**：现象学前置（零成本）→ 零训练测量批（~1 GPU·h）→ 门控探针（~3 GPU·h）→ 定向干预批（~20+ GPU·h）——每层不过线就停，不进下一层。

## 七、快速检查清单（新实验发射前）

```
□ 基线落在可分辨区间？（20 题试点，难度分布 = 正式批）
□ 每个度量的 bootstrap σ 已知？信号 > 10σ？
□ 三口径全部定义好读取方式？（id / 腐蚀 / 探针）
□ 判据已冻结进 ADR？（含方向、幅度、保护分支、触发条款）
□ 无效判读条款写明失效模式？
□ 用最小批可否买否决？（能否先跑门控/零训练版）
□ 单进程独占写输出？断点续跑就绪？
□ 校准失败的最大浪费是多少？（预估并写进 ADR 风险栏）
```
