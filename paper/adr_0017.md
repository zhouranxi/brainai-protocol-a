# ADR-0017：b 的 run 级抽样分布与跨种子可分辨性

## 一、背景与问题

ADR-0016 的 P5→P6→P7 连锁批把「幂律指数 b 的稳定性」问题推进到
当前位置：

1. **P5（附录三十三）**：s0 λ=0.3 单点 OOD 塌陷是 ~1/9 量级的
   run 级噪声，非种子固有。
2. **P6（附录三十四）**：s0 的 b=0.515 离群在换 run-seed 后回落
   到 0.394（边缘带），λ=0.03 低剂量欠响应也是 run 可变的。
3. **P7（附录三十五）**：四种子「紧致带」[0.264, 0.347] 不是
   run 稳定不变量——s1 重抽纹丝不动（−0.002），s2 重抽漂出带
   （+0.113，与 s0 的 0.121 同量级）。b 的 run 级方差本身是
   逐种子可变的属性。

**核心未决问题（本 ADR 承接）**：

- Q1：每种子的 b 抽样分布长什么样？（均值/离散度——s2 的
  +0.113 漂移是尾部事件还是常态？）
- Q2：跨种子 b 差异（若存在）在 run 级方差下**可分辨**吗？
  即：需要多少次抽样才能以预定置信度区分两种子的 b？
- Q3：b 的 run 级方差有结构吗？（与 base 几何的什么量相关？
  ——描述性，若 Q1/Q2 产出结构信号才展开）

## 二、设计（P8 批，跑前冻结）

### 测量口径（与 ADR-0016 逐字一致）

- 拟合：5 点全拟合 OLS on (log Δd, log|Δc|)（附录二十九 M3）；
- Δd/Δc 相对归档 base（full_base_lr0.125.json）；
- 割线 = (Δc/Δd)/s_obs，s_obs=0.0161；安慰剂带 0.022；
- id_keep ≥ −0.02 闸，越界点降 4 点拟合并点名。

### 预注册判读（跑前冻结）

记每种子的三次抽样 b：s0 ∈ {0.515, 0.394, b_new}，
s1 ∈ {0.325, 0.323, b_new}，s2 ∈ {0.264, 0.377, b_new}。

- **F1（分布刻画，主）**：逐种子报告三抽样的极差 W_s 与标准差
  s_s；全库报告 W = max−min。判读：
  - 若三种子各有 W_s ≤ 0.05 → P7 的分层（s1 稳/s2 漂）可能
    是第 2 次抽样的运气，b 的 run 方差小而均匀；
  - 若任一种子 W_s ≥ 0.10 → b 的 run 级方差确认非平凡，
    单种子单抽样 b 不可作跨种子统计量（附录三十五表述维持
    并加固）；
  - 其间 → 如实报告各 W_s，不做二分强判。
- **F2（跨种子可分辨性）**：以三抽样为每种子样本（n=3），
  报告两两种子的均值差与合并标准差，Welch t 的效应量
  （Cohen's d）。判读：d ≥ 2 → 该种子对在 3 抽样下可分辨
  （供功效参考）；d < 1 → 不可分辨，跨种子 b 比较需更多抽样。
  本批不做正式假设检验（n=3 无多重比较校正力）。
- **F3（功能保持）**：14 run id_keep ≥ −0.02。
- **不做的**：不动 v2 归档与五种子 b 表；s3/s4 不进本批；
  不触发论文变更（b 表是 ADR 层机制数字，论文只声称
  sub-linear——全库 b ≤ 0.515 在任何分支下不变）。

### s0 λ=0.3 点的选样注记（诚实性）

P5 C1 臂有 8 个 λ=0.3 读数（Δc 0.0387–0.0762）。第 3 条 s0
曲线的该点取 collapse_c1_seed2（Δc=0.0564，8 个读数的中位数
最近的邻域），理由：run-seed 2 的 4 个新点与 seed2 读数同链
（同 --seed 2 训练随机）；**不逐个试 8 个读数选对 b 最有利的**
（那是 garden of forking paths）。此选法跑前冻结。

### 第三抽样曲线（run-seed 2）

- s0：λ 五点 Δc = +0.0310/+0.0489/+0.0564(选样)/+0.0880/+0.0866
  → **b=0.386**（R²=0.969）
- s1：Δc = +0.0635/+0.0802/+0.1074/+0.1203/+0.1324
  → **b=0.298**（R²=0.979）
- s2：Δc = +0.0662/+0.0711/+0.1017/+0.1093/+0.1151
  → **b=0.255**（R²=0.962）

### F1（分布刻画，主判读）→ 方差非平凡确认

| 种子 | 三次抽样 b | 均值 | sd | 极差 W_s |
|---|---|---|---|---|
| s0 | 0.515 / 0.394 / 0.386 | 0.432 | 0.072 | **0.129** |
| s1 | 0.325 / 0.323 / 0.298 | 0.315 | 0.015 | 0.027 |
| s2 | 0.264 / 0.377 / 0.255 | 0.299 | 0.068 | **0.122** |

s0 与 s2 的 W_s 均超 0.10 门槛 → **「单抽样 b 不可作跨种子
统计量」确认**（附录三十五表述维持并加固）。

**结构注记（描述性，3×3 的模式）**：每种子的三次抽样呈
「两次一致 + 一次远足」形态——

- s0：0.394 与 0.386 几乎重合，0.515 是远足（首次抽样）；
- s1：0.325/0.323/0.298 全程紧致（无远足）；
- s2：0.264 与 0.255 几乎重合，0.377 是远足（第二次抽样）。

即远足不是种子固有（s1 无远足），也不是每次抽样的常态（三
种子各 3 次抽样只有 2 次远足，~22%）——**b 的抽样分布是
「紧致核心 + 低概率远足」的重尾形态**，与 P5 判定的 λ=0.3
塌陷（~1/9 run 级噪声）同族：几何干预的 run 级响应偶发大幅
波动，并非小高斯噪声。远足方向不定（s0 向上、s2 向上带内
漂移后回落）。

### F2（跨种子可分辨性）

| 种子对 | 均值差 | Cohen's d | 3 抽样下可分辨？ |
|---|---|---|---|
| s0–s1 | 0.117 | **2.23** | 是（d≥2） |
| s0–s2 | 0.133 | 1.90 | 边缘（1≤d<2） |
| s1–s2 | 0.016 | 0.34 | 否（d<1） |

- s0 的均值离群在 3 抽样下对 s1 可分辨（d=2.23）——「s0 形态
  偏高」是**分布层的真信号**，不是纯噪声；但对 s2 只在边缘
  （s2 自己的方差大，压低了 d）。
- s1–s2 完全不可分辨（d=0.34）——带内两种子无实质差异。
- **功效推论**：以「紧致核心+远足」分布做跨种子 b 比较，
  3 抽样只够分辨「离群种子 vs 紧致种子」量级的差异
  （均值差 ≥0.11）；分辨 0.05 量级差异需要每种子 ≥5 抽样
  （远足概率 ~20% 下，5 抽样均值才稳定）。生物侧比较若要
  用 b，按此最小抽样数设计。

### 收口

Q1（分布形态）已答：紧致核心 + ~20% 远足的重尾。Q2（可分辨
性）已答：3 抽样分辨 ≥0.11 差异，0.05 量级需 ≥5 抽样。
Q3（远足机制）**未答**——3×3 数据不足以定位远足的结构源
（何种 base×run-seed 组合触发远足），且远足样本仅 2 例。
按第二节占位：Q3 挂 P10 候选（需更大抽样设计的专门批），
本 ADR 现阶段收口为「分布刻画 + 可分辨性」两个可交付结论。
