# ADR-0017：b 的 run 级抽样分布与跨种子可分辨性

- 状态：进行中（P8 批已发射）
- 日期：2026-11-12 01:48 立项
- 前置：ADR-0016 附录三十四/三十五（P6/P7 批）挂账问题的承接
- 决策人：Lance（用户）；执行：WorkBuddy（无涯智）

## 一、背景与问题

ADR-0016 的 P5→P6→P7 连锁批把「幂律指数 b 的稳定性」问题推进到
当前位置：

1. **P5（附录三十三）**：s0 λ=0.3 单点 OOD 塌陷是 ~1/9 量级的
   run 级噪声，非种子固有。
2. **P6（附录三十四）**：s0 的 b=0.515 离群在换 run-seed 后回落
   到 0.394（边缘带），λ=0.03 低剂量欠响应也是 run 可变的。
3. **P7（附录三十五）**：四种子「紧致带」[0.264, 0.347] 不是
   run 稳定不变量——s1 重抽纹丝不动（−0.002），s2 重抽漂出带
   （+0.113，与 s0 的 0.121 同量级）。b 的 run 级方差本身是
   逐种子可变的属性。

**核心未决问题（本 ADR 承接）**：

- Q1：每种子的 b 抽样分布长什么样？（均值/离散度——s2 的
  +0.113 漂移是尾部事件还是常态？）
- Q2：跨种子 b 差异（若存在）在 run 级方差下**可分辨**吗？
  即：需要多少次抽样才能以预定置信度区分两种子的 b？
- Q3：b 的 run 级方差有结构吗？（与 base 几何的什么量相关？
  ——描述性，若 Q1/Q2 产出结构信号才展开）

## 二、设计（P8 批，跑前冻结）

### 数据设计

补齐每种子的第 3 条曲线，使 s0/s1/s2 各有 3 次独立抽样
（run-seed 0 归档、run-seed 1 已有、run-seed 2 新跑）：

- s0：λ∈{0.03, 0.1, 1.0, 3.0} × 4 run（λ=0.3 用 P5 C1 臂的
  seed2 读数，其分布与 D 臂曲线兼容——见判读注记）；
- s1：5 λ × 5 run；
- s2：5 λ × 5 run。
- **总 14 run**，GPU0 串行 ~7.7h（01:52 发射，预计 ~09:30）。

### 测量口径（与 ADR-0016 逐字一致）

- 拟合：5 点全拟合 OLS on (log Δd, log|Δc|)（附录二十九 M3）；
- Δd/Δc 相对归档 base（full_base_lr0.125.json）；
- 割线 = (Δc/Δd)/s_obs，s_obs=0.0161；安慰剂带 0.022；
- id_keep ≥ −0.02 闸，越界点降 4 点拟合并点名。

### 预注册判读（跑前冻结）

记每种子的三次抽样 b：s0 ∈ {0.515, 0.394, b_new}，
s1 ∈ {0.325, 0.323, b_new}，s2 ∈ {0.264, 0.377, b_new}。

- **F1（分布刻画，主）**：逐种子报告三抽样的极差 W_s 与标准差
  s_s；全库报告 W = max−min。判读：
  - 若三种子各有 W_s ≤ 0.05 → P7 的分层（s1 稳/s2 漂）可能
    是第 2 次抽样的运气，b 的 run 方差小而均匀；
  - 若任一种子 W_s ≥ 0.10 → b 的 run 级方差确认非平凡，
    单种子单抽样 b 不可作跨种子统计量（附录三十五表述维持
    并加固）；
  - 其间 → 如实报告各 W_s，不做二分强判。
- **F2（跨种子可分辨性）**：以三抽样为每种子样本（n=3），
  报告两两种子的均值差与合并标准差，Welch t 的效应量
  （Cohen's d）。判读：d ≥ 2 → 该种子对在 3 抽样下可分辨
  （供功效参考）；d < 1 → 不可分辨，跨种子 b 比较需更多抽样。
  本批不做正式假设检验（n=3 无多重比较校正力）。
- **F3（功能保持）**：14 run id_keep ≥ −0.02。
- **不做的**：不动 v2 归档与五种子 b 表；s3/s4 不进本批；
  不触发论文变更（b 表是 ADR 层机制数字，论文只声称
  sub-linear——全库 b ≤ 0.515 在任何分支下不变）。

### s0 λ=0.3 点的选样注记（诚实性）

P5 C1 臂有 8 个 λ=0.3 读数（Δc 0.0387–0.0762）。第 3 条 s0
曲线的该点取 collapse_c1_seed2（Δc=0.0564，8 个读数的中位数
最近的邻域），理由：run-seed 2 的 4 个新点与 seed2 读数同链
（同 --seed 2 训练随机）；**不逐个试 8 个读数选对 b 最有利的**
（那是 garden of forking paths）。此选法跑前冻结。
