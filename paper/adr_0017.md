## 一、背景与问题

ADR-0016 的 P5→P6→P7 连锁批把「幂律指数 b 的稳定性」问题推进到
当前位置：

1. **P5（附录三十三）**：s0 λ=0.3 单点 OOD 塌陷是 ~1/9 量级的
   run 级噪声，非种子固有。
2. **P6（附录三十四）**：s0 的 b=0.515 离群在换 run-seed 后回落
   到 0.394（边缘带），λ=0.03 低剂量欠响应也是 run 可变的。
3. **P7（附录三十五）**：四种子「紧致带」[0.264, 0.347] 不是
   run 稳定不变量——s1 重抽纹丝不动（−0.002），s2 重抽漂出带
   （+0.113，与 s0 的 0.121 同量级）。b 的 run 级方差本身是
   逐种子可变的属性。

**核心未决问题（本 ADR 承接）**：

- Q1：每种子的 b 抽样分布长什么样？（均值/离散度——s2 的
  +0.113 漂移是尾部事件还是常态？）
- Q2：跨种子 b 差异（若存在）在 run 级方差下**可分辨**吗？
  即：需要多少次抽样才能以预定置信度区分两种子的 b？
- Q3：b 的 run 级方差有结构吗？（与 base 几何的什么量相关？
  ——描述性，若 Q1/Q2 产出结构信号才展开）

### F1（分布刻画，主判读）→ 方差非平凡确认

| 种子 | 三次抽样 b | 均值 | sd | 极差 W_s |
|---|---|---|---|---|
| s0 | 0.515 / 0.394 / 0.386 | 0.432 | 0.072 | **0.129** |
| s1 | 0.325 / 0.323 / 0.298 | 0.315 | 0.015 | 0.027 |
| s2 | 0.264 / 0.377 / 0.255 | 0.299 | 0.068 | **0.122** |

s0 与 s2 的 W_s 均超 0.10 门槛 → **「单抽样 b 不可作跨种子
统计量」确认**（附录三十五表述维持并加固）。

**结构注记（描述性，3×3 的模式）**：每种子的三次抽样呈
「两次一致 + 一次远足」形态——

- s0：0.394 与 0.386 几乎重合，0.515 是远足（首次抽样）；
- s1：0.325/0.323/0.298 全程紧致（无远足）；
- s2：0.264 与 0.255 几乎重合，0.377 是远足（第二次抽样）。

即远足不是种子固有（s1 无远足），也不是每次抽样的常态（三
种子各 3 次抽样只有 2 次远足，~22%）——**b 的抽样分布是
「紧致核心 + 低概率远足」的重尾形态**，与 P5 判定的 λ=0.3
塌陷（~1/9 run 级噪声）同族：几何干预的 run 级响应偶发大幅
波动，并非小高斯噪声。远足方向不定（s0 向上、s2 向上带内
漂移后回落）。

### F2（跨种子可分辨性）

| 种子对 | 均值差 | Cohen's d | 3 抽样下可分辨？ |
|---|---|---|---|
| s0–s1 | 0.117 | **2.23** | 是（d≥2） |
| s0–s2 | 0.133 | 1.90 | 边缘（1≤d<2） |
| s1–s2 | 0.016 | 0.34 | 否（d<1） |

- s0 的均值离群在 3 抽样下对 s1 可分辨（d=2.23）——「s0 形态
  偏高」是**分布层的真信号**，不是纯噪声；但对 s2 只在边缘
  （s2 自己的方差大，压低了 d）。
- s1–s2 完全不可分辨（d=0.34）——带内两种子无实质差异。
- **功效推论**：以「紧致核心+远足」分布做跨种子 b 比较，
  3 抽样只够分辨「离群种子 vs 紧致种子」量级的差异
  （均值差 ≥0.11）；分辨 0.05 量级差异需要每种子 ≥5 抽样
  （远足概率 ~20% 下，5 抽样均值才稳定）。生物侧比较若要
  用 b，按此最小抽样数设计。

### 收口

Q1（分布形态）已答：紧致核心 + ~20% 远足的重尾。Q2（可分辨
性）已答：3 抽样分辨 ≥0.11 差异，0.05 量级需 ≥5 抽样。

## 六、P10 预注册：远足机制批——两轮设计（2026-11-12 08:05，跑前写下）

### 立项依据

P8 的 3×3 抽样把 b 的分布定格为「紧致核心 + ~20% 远足」，
但**远足的机制未知**（Q3）：何种 base × run-seed 组合触发？
现有 9 条曲线只有 2 例远足（s0_seed0、s2_seed1），无法定位
结构源。P10 的目标：把远足样本从 2 例扩大到可做组间对照的
规模，并对远足曲线做结构解剖。

### 跑前回溯分析（零 GPU，已完成，2026-11-12 08:02）

**问题**：筛查远足是否可以用 2–3 个剂量点的「廉价指纹」代替
完整 5 点曲线（把每条曲线成本从 5 run 降到 2–3 run）？

**方法**：对已有 9 条曲线分别计算 b2（λ=0.1,1.0 两点）、
b3（λ=0.1,0.3,1.0）、b3'（λ=0.03,0.1,1.0），对照 5 点 b5 的
种子内排序与极差。

**结果：廉价指纹不可用，全部方案被否决**——

| 方案 | 致命缺陷 |
|---|---|
| b2 (0.1,1.0) | s0_seed0 上算出病态 0.077（两点连线方差失控）；s1 内极差被夸大为 0.115（真实 0.027） |
| b3 (0.1,0.3,1.0) | **漏检 s0 型远足**（s0 的远足源在 λ=0.03；b3 下 s0 三抽样 0.400/0.447/0.465 反而最稳）；s1 虚假极差 0.114 |
| b3' (0.03,0.1,1.0) | 抓 s0 型，但对 s2 型（全轴缩水）捕捉打折 |

**结论**：远足可以发生在任何 λ 段（s0 在低剂量端、s2 全轴
缩水），**固定子集指纹不存在远足安全窗口，筛查必须用完整
5 点曲线**。远足检测下限 = 完整曲线。

### 设计（两轮，跑前冻结）

**第一轮（筛查轮，44 run）**：目标——**五种子的每种都有
4 条完整曲线**（对称池）。

- s3/s4：各 3 条新曲线（run-seed 3/4/5 × 5 λ = 各 15 run），
  加各自归档曲线（run-seed 0）→ 各 4 条；
- s0/s1/s2：各补 1 条（run-seed 3）。s1/s2 各 5 run；s0 的
  λ=0.3 点复用 P5 C1 臂 collapse_c1_seed3（同 run-seed 3，
  选样规则沿用第五节冻结条款）→ s0 补 4 run；
- 总 run = 15×2 + 5×2 + 4 = **44**；三链：GPU0=s3(15)、
  GPU2=s4(15)、GPU3=s0(4)+s1(5)+s2(5)=14，墙钟 ~8.5h。
- 产出 **20 条全曲线判定池**（5 种子 × 4 抽样），判读远足
  标记（G1，见下），统计远足率与种子分层。

- 成本：44 run，三卡并行，墙钟 ~8.5h。
- 为什么对称 5×4 池：P7/P8 只测了 s0/s1/s2；远足率估计
  （2/9≈22%）的置信区间太宽（95% CI [3%, 60%]）。20 条池
  把 CI 收窄到决策可用宽度（若再出现 2–5 例远足，率
  4/20–7/20 = 20–35%，Wilson CI 半宽 ~±11–20pp）；且每种
  子等池深让 G3 分层判读不偏。

**第二轮（解剖轮，仅当第一轮产出 ≥1 例新远足）**：对新
远足曲线做结构解剖——

- 与同种子核心曲线逐 λ 对照（定位远足的 λ 段：s0 型/低剂量
  vs s2 型/全轴 vs 新型）；
- 复跑远足曲线的 1–2 个关键 λ 点（run-seed 复刻远足曲线的
  seed）验证可复现性（区分「曲线级远足」vs「点级噪声聚合」）；
- 判读：若远足 λ 段集中 → 远足有结构性触发区；若分散 →
  远足是随机弥散的（与 P5 塌陷噪声同族，只是幅度更大）。

第二轮的 run 数与发射视第一轮结果定（本预注册只锁第一轮
与第二轮的条件触发条款）。

### 预注册判读（跑前冻结）

- **G1（远足标记，定义）**：一条曲线判「远足」iff 其 b 与
  同种子**核心 b**（该种子全部曲线 b 的中位数）之差 ≥ 0.08。
  （0.08 = s1 的核心内极差 0.027 的 3 倍，且小于已知远足

- **G2（远足率）**：报告总远足率 k/n 与 Wilson 95% CI；
  种子分层率。判读：
  - 总率 ≥ 15% → 远足是**常态属性**：跨种子 b 比较的抽样
    设计必须显式建模远足（报告每种子中位数而非均值）；
  - 总率 < 15% 且新批 0 远足 → 远足可能集中于 s0/s2 的
    特异性：表述降格为「部分种子偶发」；
  - 其间 → 如实报告。
- **G3（种子分层）**：s3/s4 的远足率 vs s0/s1/s2 的（4/9 vs
  新数据）。若 s3/s4 五抽零远足而 s0/s2 有 → 分层假设增强
  （远足集中于特定种子）；若 s3/s4 也出现 → 远足是种子通性。
- **G4（功能保持）**：全部 run id_keep ≥ −0.02。
- **不做的**：不动既有归档；不触发论文变更；第一轮结束前

### 重大发现：s0_seed3 超级远足 b=0.886（独立复核确认）

s0 的第 4 次抽样出现 **b=0.886, R²=0.883**——比 s0 前三次
（0.515/0.394/0.386）高出一倍以上，全库首次突破 0.6。逐点
解剖：

- **λ=0.03：Δc=+0.0039**（带内！安慰剂带 0.022）而 Δd=4.13
  正常——低剂量响应完全失灵（四次抽样 λ=0.03 的 Δc：
