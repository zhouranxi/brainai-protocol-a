  本 ADR 检验下一个指标「**流形光滑性**」；方法论沿用
  ADR-0021 三口径规范与既有干预语料

## 一、问题（三分支，全部预注册）

光滑性（smoothness）是主论文未触及的优雅性指标。问它
三个问题，每种答案都是可发表结果：

- **S-a（label）**：干预改变光滑性但光滑性不携带超越
  D_eff 的行为信息 → 优雅性家族系统检验，主论文 sequel；
- **S-b（knob）**：某种干预使光滑性改善且行为真实增益
  （三口径：ID/c10c/探针都过）→ **第一个真旋钮**；
- **S-c（更好 marker）**：光滑性作为 shift marker 的排名
  稳定性优于 D_eff（measurement 论文的翻号问题）→
  直接回答 marker-ranking 开放问题。

## 二、光滑性操作化（跑前冻结）

三个互补度量，全部定义在 penultimate 特征上（沿用既有
特征提取管线）：

1. **S-loc 局部各向异性**：kNN 邻域的局部 PCA 奇异值
   谱的熵 H_loc（越高越光滑）；对每类取中位后全局平均；
2. **S-curv 局部曲率**：三元组中点偏差率（kNN 边中点
   到流形的投影残差/边长，kNN 图代理）；
3. **S-conf 类间间隔比**：类内最近质心距 vs 类内 kNN
   距——原型性「光滑性 vs 可分性」对照。

**Phase 0（本次发射）**：对既有 68 个 ckpt_grid 基线 +
P8/P10 剂量轴 forcing checkpoint（~30 个）提取特征并
计算三度量，关联既有三口径读数——**零训练**。

### 判读（冻结）

- **F-a（marker 检验，主判读）**：跨 8 个 recipe 的
  光滑性-迁移相关 r(S, c100) vs 既有 r(D_eff, c100)=+0.97
  ——|r(S)| ≥ |r(D_eff)| 且符号稳定 → S-c 立项信号；
- **F-b（干预响应检验）**：whiten forcing 剂量轴上
  ΔS vs Δ行为（既有 P8 曲线）——若 ΔS 与 ΔD_eff 同向
  且行为传导已判为零（ADR-0021 全库结论），则光滑性
  与 D_eff 同病（label 分支加强）；若 ΔS 与行为相关
  而 ΔD_eff 不相关 → 光滑性携带 D_eff 没有的信息
  （S-b/S-c 信号）；
- **F-c（健康闸）**：每度量在 placebo 扰动（同图随机
  重排标签）下的零分布覆盖，防伪相关。
- **Phase 1 触发条款**：F-a 或 F-b 任一给出立项信号 →
  定向干预批（光滑性作为目标算子的对照实验，~20 GPU·h，
  独立预注册）；全无信号 → P19 以「优雅性家族第二指标
  亦为 label」收口（仍写入论文 sequel 素材）。

## 四、P19 跑后段（占位，跑后填）

## 五、P19 跑后段与收口（2026-11-21 01:55，跑后如实记录）

Phase 0 完成：68 基线 + 8 剂量轴（P8/P10 whiten forcing），
三度量 S-loc/S-curv/S-conf + placebo 零分布。剂量轴在学校机
GPU2 单进程收齐（此前两残留进程并发写同一 JSON 已清，
改单链独占；8 点 ~9 分钟）。

### F-a（marker 检验，主判读，68 基线跨 8 recipe）

| 度量 | r(S, c100) | r(S, D_eff) | 参照 r(D_eff,c100) |
|---|---|---|---|
| S-loc | +0.767 | +0.550 | **+0.886** |
| S-curv | +0.512 | +0.309 | +0.886 |
| S-conf | −0.731 | −0.550 | +0.886 |

三度量都是中等强度 marker（0.5–0.77），但**没有一个超过
D_eff 的 0.886**，且都与 D_eff 中度相关（0.3–0.55）——
光滑性携带的迁移信息大体是 D_eff 的子集。**S-c（更好
marker）不成立。**

### F-b（干预响应检验，剂量轴 8 点）

剂量轴上 S 随 λ 单调：ΔS-loc +0.05/+0.06（几乎不动）、
ΔS-conf −0.99/−1.05（大）、ΔD_eff +8.45/+9.15（巨大）；
行为 id 全程平坦（0.876–0.881，Δ≈0）。相关：
r(S-loc, c100)=+0.986、r(S-loc, D_eff)=+0.926、
r(S-conf, c100)=−0.975——**但行为口径 r(S, id)=+0.17/−0.14（无相关）**。

判读（按冻结条款）：

- **S-loc / S-conf 与 D_eff 同向响应、且行为传导为零** →
  命中「光滑性与 D_eff 同病」分支 = **S-a（label）确认**：
  光滑性随干预移动（不是死量），但不携带任何行为信息，
  与 D_eff 同属「响应变量」而非「因果旋钮」；
- **S-b（knob）不成立**：剂量轴上行为 id 全程零传导
  （与 ADR-0021 全库 12/12 零传导一致），无真实增益可归因；
- **剂量轴 r(S-loc,c100)=0.986 是 1-D 单调扫描的共线性
  假象**（λ 同时单调推高 c100/D_eff，任何随 λ 动的量都
  r≈1）——**不得与跨 68 模型的 F-a 0.767 混读**；marker
  排名的有效证据是 F-a（0.77 < 0.89），即光滑性弱于 D_eff。

### 附带真发现（描述性，非决策输入）

光滑性家族内部动态范围分化明显：**S-loc（局部谱熵）对
forcing 几乎不变**（Δ~2.4% 相对），**S-conf（类间隔比）
大幅移动**（Δ~55% 相对）而方向相反——家族里「局部几何」
与「全局可分性」对同一干预的响应量级差 20 倍。这与
measurement 论文的「marker 在不同 shift 类型间翻号」互为
印证：不存在单一光滑性量同时稳健响应干预 + 稳定排名。

### 处置（按冻结条款）

- **F-a / F-b 均无 Phase 1 立项信号**（S-b 不成立、
  S-c 不成立）→ **定向干预批不触发**；
- **P19 以 S-a 收口**：「优雅性家族第二指标（流形光滑性）
  亦为 label——响应干预、与行为正交、作 marker 弱于 D_eff」
  ；这是主论文「几何是 label 不是 knob」论题在**光滑性
  维度**上的延伸，仍写入论文 sequel 素材；
- 方法遗产：1-D 剂量轴的共线性假象（r≈1 不可外推）+
  多进程并发写同一 JSON 的竞态（改单链独占），两条都入
  仓库执行规范。
