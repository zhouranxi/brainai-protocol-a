# ADR-0019：层级反馈增益的载体裁决——「重塑」还是「引导」

## 一、研究问题

带层级反馈模块的网络（top-down 通路）性能优于纯前馈——
这个增益的**载体**是什么？

- **重塑假说（reshape）**：反馈在**训练时**改变了表征本身
  ——前馈权重学到更高效/更鲁棒的表征，增益是静态表征属性；
- **引导假说（guide）**：反馈在**推理时**引导计算过程——
  表征本身不更优，增益来自测试时的跨层信息流动（动力学
  属性，与「层级先验引导推理」直接对应）。

这是 ADR-0016「label not knob」范式在新问题上的移植：
观察性优势（反馈网络更好）不回答载体问题，需要干预裁决。

## 二、三配置设计（控制变量）

同一基座（CIFAR-10 小型 ResNet：3 stage × 2 block，宽度
64/128/256），三种配置共享全部前馈权重结构：

| 配置 | 时间步 | 跨层反馈 | 作用 |
|---|---|---|---|
| FF（前馈） | T=1 | 无 | 基线 |
| REC（循环） | T=3 | 无（仅同层横向自连接） | 控制「迭代计算预算」 |
| HFB（层级反馈） | T=3 | 有（top-down 1×1 conv 投影，深层→浅层调制） | 实验组 |

**关键控制**：REC 与 HFB 唯一的差是反馈是否**跨层**携带
层级信息（=「层级先验」的操作化）；两者迭代预算与参数量
匹配（±5%，横向通路 vs top-down 通路同阶）。

## 三、裁决机制：训练×推理交换

HFB/REC 的反馈在**推理时可开关**（开=完整迭代推理；关=
T=1 单步前馈）。核心交换格：

| 训练 \ 推理 | 开 | 关（T=1） |
|---|---|---|
| FF | —（=原配） | =原配 |
| REC | 原配 | REC-off |
| HFB | 原配 | **HFB-off** |

**增益分解**（主裁决量）：记 FF/REC/HFB 原配精度为
A_ff/A_rec/A_hfb，HFB 关反馈推理精度为 A_hfb_off：

- 总增益 G = A_hfb − A_ff
- 重塑份额（训练时载体）：r = (A_hfb_off − A_ff) / G
- 引导份额（推理时载体）：q = (A_hfb − A_hfb_off) / G
- r + q = 1（定义恒等；SECoff 同理得 REC 的分解）

## 四、N1 首批预注册（跑前冻结）

### 设计

- 训练：3 配置 × 3 种子 = 9 run，CIFAR-10，100ep，同协议
  （lr 0.1 cosine、wd 5e-4、SGD momentum 0.9、batch 128、
  标准增广），out 到 `runs/v2_hierarchy/n1_{cfg}_s{seed}`。
- 测量（每 run 终态）：
  1. ID test acc（原配推理）；
  2. **交换读数**：REC/HFB 另测 off 推理（T=1）精度——
     训练结束时同一 checkpoint 双推理，零额外训练成本；
  3. 表征质量：d_ent + GLUE（复用 `train_forcing_p4.py` 的
     `d_ent_of`/`glue_dimension`/`linear_probe_acc` 链路）
     + c100 探针（OOD 转移口径）；
  4. 训练曲线（train/test per epoch）。
- 资源：小 ResNet 100ep ~15-25min/run；GPU0/GPU2 双链，
  墙钟 ~1.5-2h。

### 判读（冻结）

- **R1（主裁决：载体分解）**：以 c100 探针与 ID test 双口径
  分别计算 q（引导份额）：
  - q ≥ 2/3（两口径一致）→ **引导主导**：反馈增益主要是
    推理时动力学——「层级先验引导推理」的直接证据；
  - q ≤ 1/3（两口径一致）→ **重塑主导**：反馈主要通过训练
    改善静态表征；
  - 口径不一致或中间值 → 如实报告分解（r, q），不二分强判。
- **R2（层级特异性）**：A_hfb − A_rec（同迭代预算下跨层
  反馈的净贡献）。若 ≈0 → 增益来自迭代计算本身，与层级
  无关，「层级先验」叙事不成立；若 >0（跨种子一致）→
  层级信息有特异性贡献。
- **R3（几何签名）**：三配置 d_ent/GLUE 对照。若 HFB 的
  几何量与 FF 显著不同且方向与增益一致 → 重塑的几何证据；
  若几何无差而行为有差 → 引导的旁证（表征同、过程异）。
- **R4（功能保持）**：全部 run 的 ID test ≥ 90%（训练健康
  闸，低于者点名并查训练曲线）。
- **不做的**：不动 ADR-0016~0018 归档；首批不做 CIFAR-10-C
  （留 N2）；不做 FF 训练 + HFB 推理格（需要反馈权重，
  联合训练问题，注册为 N2 候选）；论文零触发（先 ADR）。
