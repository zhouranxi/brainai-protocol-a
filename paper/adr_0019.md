# ADR-0019：层级反馈增益的载体裁决——「重塑」还是「引导」

- 前置：ADR-0016~0018 方法论传承（干预增益的载体裁决范式；

## 一、研究问题

带层级反馈模块的网络（top-down 通路）性能优于纯前馈——
这个增益的**载体**是什么？

- **重塑假说（reshape）**：反馈在**训练时**改变了表征本身
  ——前馈权重学到更高效/更鲁棒的表征，增益是静态表征属性；
- **引导假说（guide）**：反馈在**推理时**引导计算过程——
  表征本身不更优，增益来自测试时的跨层信息流动（动力学
  属性，与「层级先验引导推理」直接对应）。

这是 ADR-0016「label not knob」范式在新问题上的移植：
观察性优势（反馈网络更好）不回答载体问题，需要干预裁决。

## 二、三配置设计（控制变量）

同一基座（CIFAR-10 小型 ResNet：3 stage × 2 block，宽度
64/128/256），三种配置共享全部前馈权重结构：

| 配置 | 时间步 | 跨层反馈 | 作用 |
|---|---|---|---|
| FF（前馈） | T=1 | 无 | 基线 |
| REC（循环） | T=3 | 无（仅同层横向自连接） | 控制「迭代计算预算」 |
| HFB（层级反馈） | T=3 | 有（top-down 1×1 conv 投影，深层→浅层调制） | 实验组 |

**关键控制**：REC 与 HFB 唯一的差是反馈是否**跨层**携带
层级信息（=「层级先验」的操作化）；两者迭代预算与参数量
匹配（±5%，横向通路 vs top-down 通路同阶）。

## 三、裁决机制：训练×推理交换

HFB/REC 的反馈在**推理时可开关**（开=完整迭代推理；关=
T=1 单步前馈）。核心交换格：

| 训练 \ 推理 | 开 | 关（T=1） |
|---|---|---|
| FF | —（=原配） | =原配 |
| REC | 原配 | REC-off |
| HFB | 原配 | **HFB-off** |

**增益分解**（主裁决量）：记 FF/REC/HFB 原配精度为
A_ff/A_rec/A_hfb，HFB 关反馈推理精度为 A_hfb_off：

- 总增益 G = A_hfb − A_ff
- 重塑份额（训练时载体）：r = (A_hfb_off − A_ff) / G
- 引导份额（推理时载体）：q = (A_hfb − A_hfb_off) / G
- r + q = 1（定义恒等；SECoff 同理得 REC 的分解）

## 四、N1 首批预注册（跑前冻结）

### 设计

- 训练：3 配置 × 3 种子 = 9 run，CIFAR-10，100ep，同协议
  （lr 0.1 cosine、wd 5e-4、SGD momentum 0.9、batch 128、
  标准增广），out 到 `runs/v2_hierarchy/n1_{cfg}_s{seed}`。
- 测量（每 run 终态）：
  1. ID test acc（原配推理）；
  2. **交换读数**：REC/HFB 另测 off 推理（T=1）精度——
     训练结束时同一 checkpoint 双推理，零额外训练成本；
  3. 表征质量：d_ent + GLUE（复用 `train_forcing_p4.py` 的
     `d_ent_of`/`glue_dimension`/`linear_probe_acc` 链路）
     + c100 探针（OOD 转移口径）；
  4. 训练曲线（train/test per epoch）。
- 资源：小 ResNet 100ep ~15-25min/run；GPU0/GPU2 双链，
  墙钟 ~1.5-2h。

### 判读（冻结）

- **R1（主裁决：载体分解）**：以 c100 探针与 ID test 双口径
  分别计算 q（引导份额）：
  - q ≥ 2/3（两口径一致）→ **引导主导**：反馈增益主要是
    推理时动力学——「层级先验引导推理」的直接证据；
  - q ≤ 1/3（两口径一致）→ **重塑主导**：反馈主要通过训练
    改善静态表征；
  - 口径不一致或中间值 → 如实报告分解（r, q），不二分强判。
- **R2（层级特异性）**：A_hfb − A_rec（同迭代预算下跨层
  反馈的净贡献）。若 ≈0 → 增益来自迭代计算本身，与层级
  无关，「层级先验」叙事不成立；若 >0（跨种子一致）→
  层级信息有特异性贡献。
- **R3（几何签名）**：三配置 d_ent/GLUE 对照。若 HFB 的
  几何量与 FF 显著不同且方向与增益一致 → 重塑的几何证据；
  若几何无差而行为有差 → 引导的旁证（表征同、过程异）。
- **R4（功能保持）**：全部 run 的 ID test ≥ 90%（训练健康
  闸，低于者点名并查训练曲线）。
- **不做的**：不动 ADR-0016~0018 归档；首批不做 CIFAR-10-C
  （留 N2）；不做 FF 训练 + HFB 推理格（需要反馈权重，
  联合训练问题，注册为 N2 候选）；论文零触发（先 ADR）。

## 六、N1′ 跑后段：仍判无效（架构缺陷），N1″ 修订重发（2026-11-15 16:20）

9/9 完成（10:19 发射）。R4 仍 FAIL：FF 0.947-0.949 健康、
REC **0.513-0.522**、HFB **0.668-0.676**（不再随机崩溃，
但远低于 0.90 闸）。

**诊断（训练曲线 + off 读数联合）**：

1. REC/HFB 从 ep10 起就系统性落后 FF（test 0.35/0.57 vs
   0.64）——迭代通路**全程拖累**，不是晚期过拟合；
2. ep40+ 二次崩溃（train→0.97 而 test→0.19-0.24）——
   过拟合成分仍在，但早停 best 只到 0.51/0.67，救不回；
3. **关键证据：off(T=1) 读数 0.26-0.50**——前馈权重本身被
   迭代训练拖垮（若只有推理步受损，off 应接近 FF）。

**根因：架构设计缺陷**——迭代步里的「第二遍 block 过卷」
（复用 stage 第二块做再精炼）让特征被过度变换：共享卷积
在一次前向里重复施加，等效于极深的未归一化合成，训练
信号被搅乱。这是 N1/N1′ 两轮的共同病灶（N1 崩得更彻底
是因为无正则放大了它）。

### N1″ 设计修订（跑前冻结）

迭代步**轻量化**：去掉全部「第二遍 block」，只保留纯调制
残差——REC 为门控自连接（z + σ(lat(z))·z），HFB 为
top-down 残差（z + tanh(td(z')↑)）。迭代步零新增卷积
深度，与 FF 的唯一差异就是调制项本身。这正是「反馈=
调制」的最小干净实现。协议（wd 2e-3、RandAugment、
早停、100ep）与其余判读逐字不变。

### 附带观察（无效批次内，不作判读依据）

R2 的 A_hfb−A_rec = [+0.155, +0.161, +0.153] 三种子惊人
一致——即使在被拖垮的状态下，跨层反馈仍稳定优于纯迭代
+15.5pp。若 N1″ 健康通过，此信号的干净版本将是层级
特异性的强候选证据（届时重测，不引用本批）。

|---|---|---|---|---|

### R1 主裁决：G≈0，无可分解增益

**ID 口径三配置无差**（G = −0.0008）：层级反馈在该实现下
对 ID 精度零增益（q 分解失去意义，除零保护下形式输出
不采信——冻结判读的「G≈0: no gain to decompose」分支）。
off=原配（HFB 的调制残差推理时开与关同读数）：调制幅度
训练后收敛到近零（tanh 饱和前的小权重），推理时不再携带
信息。**「无害但不增益」**——轻量调制在 100ep 内没有学会
用跨层信息。

### R2：层级特异性小幅存在（ID 口径 +0.5pp 一致）

A_hfb−A_rec = [+0.006, +0.005, +0.003] 三种子同号，但幅度
仅 0.3–0.6pp（N1′ 废墟里的 +15.5pp 是病态下的，不成立）。

### R3：c100 口径出现分离——但方向出乎意料

**REC 的 c100 = 0.135–0.138，比 FF/HFB（0.095–0.097）高
+4pp**。同层横向自连接（无层级信息）改善了 OOD 迁移，
而跨层 top-down 反馈**没有**（HFB 回落 FF 水平）。d_ent
侧写：REC 3.29 最高，其表征最「扩展」。

### 判读（按冻结规则如实）

1. **R1 落「G≈0」分支**：当前实现的层级反馈对 ID 无增益
   ——「重塑 vs 引导」的裁决问题在 N1″ 上**不成立**（无
   增益可分解）。这不是假说被否，是测试架的增益没有出现。
2. **R2 小幅层级特异**（+0.5pp）与 **R3 的 REC-OOD 优势**
   （+4pp）是两个超出主问题的真实信号，值得追问。
3. 可能性分析（描述性）：调制残差太轻（tanh 无缩放因子，
   初始化下输出幅度小，梯度可能不足以把 top-down 通路
   「唤醒」）——N1′ 的教训表明重了会崩、N1″ 表明轻了
   不学，增益窗口在两者之间。
