# ADR-0032：R1 假设维持效应的解构——历史 × 格式 2×2 对照

- 状态：已完成，R1a/R1b 双过，交互项为头条发现
- 日期：2026-11-23 18:00 立项；18:03 发射；21:15 完成（1080/1080）并判读
- 动机：机制文（切法 α）§7 主张「假设维持机制（M-c）的早期召回优势来自把候选历史留在上下文中」。但 M-c 与无状态对照的差异不止历史一处——还包含「列 ≥3 候选 + 把握% + 证据说明」的输出格式要求。历史与格式混在一起，审稿人必问的 confound。

## 一、设计

### 2×2 因子

| | 全格式 F+（≥3候选+把握%） | 单答案 F− |
|---|---|---|
| **有历史 H+**（对话更新） | M-c（已有，P31 批） | M-b（已有，P31 批） |
| **无历史 H−**（单轮调用） | **b3（本批新跑）** | **b4（本批新跑）** |

- b3 prompt = M-c 的第一轮 prompt 原文，用于每一级：
  `谜题：{q}\n{第g级线索}\n列出至少三个候选假设，按把握排序，每个附把握百分比。证据不足时禁止收敛到单一答案。`
- b4 prompt = M-b 的第一轮 prompt 原文，用于每一级：
  `谜题：{q}\n{第g级线索}\n直接给出你最有把握的一个答案，并简述理由。`
- 最小改动原则：b3/b4 就是「把 M-c/M-b 的首轮 prompt 独立用于各线索级」，不引入任何新措辞。

### 口径（与 P31 批完全对齐）

- 谜题：60 新题（P31–P90，七类模板，难度分层）
- 温度 0.7 × 3 重采样，题级 rank 取中位
- 打分器：v4（把握%锚定 gold_rank + dup 计数），与 P25 v2/P31 批同一实现
- 旧 30 题（temp 0）不进主判据，仅作附录参照

### 工作量

2 臂 × 60 题 × 3 级 × 3 rep = **1080 问**（两臂均为单轮调用，快于 M-c）。预计 2–3 h。

## 二、冻结判据（发射前锁定）

主读出：**top-3 recall @ G1、G2**（60 题，中位 rank；recall = rank ∈ {1,2,3}）。

ANOVA 式分解（G2 为主，G1 复核）：

- **H 主效应** = ½[(M-c − b3) + (M-b − b4)]，题级配对后做双侧 sign test
- **F 主效应** = ½[(M-c − M-b) + (b3 − b4)]，同上
- 交互 = (M-c − b3) − (M-b − b4)

裁决（发射前冻结）：

| 判据 | 闸门 | 含义 |
|---|---|---|
| **R1a 历史主张** | H 主效应 @G2 ≥ +10pp 且 p < 0.05 | 收益确实来自假设维持 → 机制文 §7 坐实 |
| **R1b 格式主张** | F 主效应 @G2 ≥ +10pp 且 p < 0.05 | 收益（部分）来自输出纪律 → §7 需重新归因、改稿 |

- 双过：混合来源，报告各自份额（正文改写为分解表述）
- 双不过：R1 在干净对照下不稳 → 升级问题，机制文 §7 降级为「提示工程敏感性」

次要读出（不设闸门）：

1. **dup 占位重复的四臂分布**：若 b3（有格式无历史）也出 dup → dup 是格式诱导的；若只有 M-c 出 → dup 需要历史参与，现象更深层
2. G3 终局 top-1 四臂对照（预期：历史臂与无历史臂在终局合流，与 M-d 提前收敛效应互证）

## 五、判读（2026-11-23 21:15）

### 四臂结果（60 题，中位 rank，recall = gold ∈ top-3）

| 臂 | G1 | G2 | G3 | G1 top1 | G2 top1 | G3 top1 |
|---|---|---|---|---|---|---|
| M-c（历史+全格式） | 30/60 | 50/60 | 60/60 | 18 | 26 | 48 |
| b3（无历史+全格式） | 30/60 | 32/60 | 47/60 | 22 | 23 | 43 |
| M-b（历史+单答案） | 15/60 | 21/60 | 46/60 | 15 | 21 | 46 |
| b4（无历史+单答案） | 23/60 | 22/60 | 44/60 | 23 | 22 | 44 |

### 冻结闸门裁决

- **R1a 历史主张 PASS**：H 主效应 @G2 = +14pp（F+ 臂 +30pp / F− 臂 −2pp），配对 sign p < 10⁻⁴
- **R1b 格式主张 PASS**：F 主效应 @G2 = +32pp（H+ 臂 +48pp / H− 臂 +17pp），配对 41正/1负，p < 10⁻⁴
- 双过 → 按预注册条款报「混合来源」，但见下：这不是简单相加。

### 头条：交互项

H 效应在两种格式下不对称：F+ 臂 +30pp vs F− 臂 −2pp，交互 = +32pp，逐题 sign p = 0.0001。
**历史的收益几乎完全依赖全格式共同实现**：单答案格式下维持历史无收益（甚至 G1 为负），
全格式下历史把格式纪律的潜力兑现（+30pp）。M-c 的早期优势 = 格式给出「多假设空间」×
历史给它「内容」。格式是必要条件，历史是放大器。

G1 已现端倪：b3（无历史+全格式）G1 recall = M-c 持平（30/60），说明「列三个带把握」
本身在第一级就建立了候选空间；历史的作用从 G2 才开始兑现。

### 次要读出

1. **dup 占位重复 = 格式诱导，历史放大**：G2 平均 dup —— M-c 1.18（36/60 题出现）>
   b3 0.57（18/60）> M-b/b4 0.00。单答案格式永不产生 dup（结构上不可能），全格式
   无历史即可产生（0.57），历史使其翻倍。修正机制文原表述（「维持机制的失败面」）：
   dup 是「列三候选」指令与语义收敛的冲突面，不是「维持」独有的。
2. **G3 终局合流**：四臂 top-1 72–80%，全格式略高（80/72 vs 77/73）但差距小——
   再次确认早期效应才是机制差异所在，与 M-d 提前收敛效应互证。

### 对机制文的影响

- §7 主张需改写：「maintained set is load-bearing」不成立——单靠历史（M-b vs b4）
  无收益；改为：**格式建立候选空间（必要条件），历史在证据积累中兑现它（放大器）**。
- §7 第 3 条 dup 归因改写：dup 属于格式，不专属于维持。
- 新增 2×2 小节作为稳健性/解构检验，主图 (b) 可补 b3 点。
