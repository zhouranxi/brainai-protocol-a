# ADR-0032：R1 假设维持效应的解构——历史 × 格式 2×2 对照

- 状态：已预注册，待发射
- 日期：2026-11-23 18:00 立项
- 动机：机制文（切法 α）§7 主张「假设维持机制（M-c）的早期召回优势来自把候选历史留在上下文中」。但 M-c 与无状态对照的差异不止历史一处——还包含「列 ≥3 候选 + 把握% + 证据说明」的输出格式要求。历史与格式混在一起，审稿人必问的 confound。

## 一、设计

### 2×2 因子

| | 全格式 F+（≥3候选+把握%） | 单答案 F− |
|---|---|---|
| **有历史 H+**（对话更新） | M-c（已有，P31 批） | M-b（已有，P31 批） |
| **无历史 H−**（单轮调用） | **b3（本批新跑）** | **b4（本批新跑）** |

- b3 prompt = M-c 的第一轮 prompt 原文，用于每一级：
  `谜题：{q}\n{第g级线索}\n列出至少三个候选假设，按把握排序，每个附把握百分比。证据不足时禁止收敛到单一答案。`
- b4 prompt = M-b 的第一轮 prompt 原文，用于每一级：
  `谜题：{q}\n{第g级线索}\n直接给出你最有把握的一个答案，并简述理由。`
- 最小改动原则：b3/b4 就是「把 M-c/M-b 的首轮 prompt 独立用于各线索级」，不引入任何新措辞。

### 口径（与 P31 批完全对齐）

- 谜题：60 新题（P31–P90，七类模板，难度分层）
- 温度 0.7 × 3 重采样，题级 rank 取中位
- 打分器：v4（把握%锚定 gold_rank + dup 计数），与 P25 v2/P31 批同一实现
- 旧 30 题（temp 0）不进主判据，仅作附录参照

### 工作量

2 臂 × 60 题 × 3 级 × 3 rep = **1080 问**（两臂均为单轮调用，快于 M-c）。预计 2–3 h。

## 二、冻结判据（发射前锁定）

主读出：**top-3 recall @ G1、G2**（60 题，中位 rank；recall = rank ∈ {1,2,3}）。

ANOVA 式分解（G2 为主，G1 复核）：

- **H 主效应** = ½[(M-c − b3) + (M-b − b4)]，题级配对后做双侧 sign test
- **F 主效应** = ½[(M-c − M-b) + (b3 − b4)]，同上
- 交互 = (M-c − b3) − (M-b − b4)

裁决（发射前冻结）：

| 判据 | 闸门 | 含义 |
|---|---|---|
| **R1a 历史主张** | H 主效应 @G2 ≥ +10pp 且 p < 0.05 | 收益确实来自假设维持 → 机制文 §7 坐实 |
| **R1b 格式主张** | F 主效应 @G2 ≥ +10pp 且 p < 0.05 | 收益（部分）来自输出纪律 → §7 需重新归因、改稿 |

- 双过：混合来源，报告各自份额（正文改写为分解表述）
- 双不过：R1 在干净对照下不稳 → 升级问题，机制文 §7 降级为「提示工程敏感性」

次要读出（不设闸门）：

1. **dup 占位重复的四臂分布**：若 b3（有格式无历史）也出 dup → dup 是格式诱导的；若只有 M-c 出 → dup 需要历史参与，现象更深层
2. G3 终局 top-1 四臂对照（预期：历史臂与无历史臂在终局合流，与 M-d 提前收敛效应互证）
