# ADR-0018：λ=0.03 失灵表型的机制解剖——P12

- 状态：终收口（P12 分岔+锁定机制 + P13 剂量单调解锁，36 run 完整闭环）
- 日期：2026-11-14 00:38 立项
- 前置：ADR-0017 P10（15% 远足率 + λ=0.03 失灵机制定位）与
  2026-11-14 零 GPU 探针（失灵 run 的 Δd 矮 30–50%、轨迹
  ep20–100 平台期、ID 健康）
- 决策人：Lance（用户）；执行：WorkBuddy（无涯智）

## 一、问题与已有证据

ADR-0017 判定：b 远足的充分机制是 λ=0.03 低剂量响应失灵
（15% 概率，same-seed 复刻不复现）。零 GPU 探针（2026-11-14
00:30，3 失灵 vs 9 健康，全部 λ=0.03）发现失灵 run 共享一个
连贯表型：

1. **Δd 矮 30–50%**：失灵 3.3/4.1 vs 健康 6.6–10.2——
   forcing 没把 d 推上去（推翻「d 上去 c 没跟上」的旧理解）；
2. **轨迹前半平台**：失灵 run 的 d_ent 在 ep20–100 卡在
   10–14，健康 run 一路 13→19；
3. **ID 健康**（test 0.877）、glue_r 无异样——故障局限在
   几何传导链。

**本 ADR 要回答的机制问题**：失灵在训练过程里何时发生、
由什么承载——(a) 早期锁定（ep<40 的权重状态决定整 run
命运）还是 (b) 后期分化（ep40 时失灵与健康还不可区分）？
失灵 run 的 forcing loss 分量是否从一开始就与健康分离
（「未咬合」假说）？

## 二、设计（跑前冻结）

### 仪表补丁（对 train_forcing_p4.py 的三处最小改动）

1. 最终 run JSON 的行加 `"history"` 字段（per-epoch 的
   train/test/forcing_loss，训练时已在 `hist` 内计算，只是
   此前未随 JSON 落盘）；
2. `ep==40` 时额外保存权重快照 `{tag}__{kind}_lam{lam}_ep40snap.pt`
   （不覆盖滚动 checkpoint；ep40 是探针平台上第一拐点前）；
3. `--resume-snap PATH` 参数：加载快照权重后按常规协议继续
   训练（optimizer/scheduler 重置，训练随机由 --seed 驱动）。
   默认路径（不带该参数）行为与历史协议逐字一致。

### M1a（收集批，16 run）

s0、s3 各 8 个 run-seed（7..14，避开已用的 0–6），λ=0.03，

## 三、预注册判读（跑前冻结）

### K1（M1a 主判读：失灵的时序定位）

- 记每 run 前 40ep 平均 forcing_loss（history 直接可算）

### J1（M1b 判读：失灵由什么承载）

- 失灵源分叉的 4 个 run 中 **≥2 个仍失灵**（|Δc|≤0.022）

- **0/4 失灵** → 失灵由 ep40 之后的随机性承载（后期分化），
  ep40 权重可自愈；
- 1/4 → 混合，如实报告。
- 健康源对照的失灵数并列报告（基线漂移检查；若健康源也
  出 ≥2 失灵则「锁定」判读降格为「分叉方差大」）。

**失灵源分叉 4/4 仍失灵、健康源分叉 0/4 失灵** → 按冻结

### 合并机制图景（M1a + M1b）

1. 失灵/健康在 **ep40 前的标量 forcing loss 上不可区分**
   （K1 OVERLAP，0.058–0.083 同域）；
2. 但 **ep40 时刻的几何状态已经分岔**：失灵源 d=14.65 vs

3. 从分岔点出发，**任何后续训练随机都不能翻盘**（4/4 vs

   的势垒高到 160ep 的持续 forcing（λ=0.03）+ 4 种随机
   都无法跨越。

**机制结论（ADR-0018 交付）**：λ=0.03 失灵 = **前 40ep
内几何状态的双稳态分岔**——whiten forcing 在低剂量下以
~28-44% 概率把表征推入「低 d 盆地」，进入后不可逆（对
该剂量）。标量 loss 全程无法预警；唯一早期信号是 d 轨迹
本身（ep40 已可判）。这同时解释了 ADR-0017 的全部三个
现象：b 远足的杠杆（失灵点钉死曲线首点）、same-seed 不
复现（分岔由 GPU 非确定性触发）、失灵率区间宽（分岔概率
对初始化/环境敏感）。

## 七、P13 预注册：跨剂量解锁批（2026-11-14 20:18，跑前写下）

### 立项依据

ADR-0018 第六节判定：失灵 = 前 40ep 双稳态几何分岔，进入
低 d 盆地后**对该剂量（λ=0.03）不可逆**（160ep 持续 forcing
翻不了盘）。遗留的直接追问：**锁定是剂量特异的还是绝对的**
——更高的 forcing 剂量（λ=0.3/1.0/3.0）能否把表征从失灵
盆地中拉出来？这决定「低 d 盆地」的物理图景：是 λ=0.03 的
势垒问题（剂量够就能跨），还是表征被推入了一个任何 whiten
剂量都无法逃逸的深井（几何干预的绝对不可逆性）。

### 设计（跑前冻结）

- **L 臂（解锁批，12 run）**：取 M1b 已验证的失灵源快照
  （s0_seed7 的 ep40，M1b 分叉 4/4 复现失灵——「标准失灵
  盆地」标本）与 M1a 另一失灵快照（s0_seed13 ep40，独立
  失灵样本）。两个失灵源 × 三档高剂量 λ∈{0.3, 1.0, 3.0}
  × 2 个分叉 seed（201/202），--resume-snap 续训，200ep
  协议同源。GPU0/GPU2 双链，~4h。
- 健康对照不需要新 run：历史 hi λ∈{0.3,1,3} 曲线已有
  （从 base 训练的健康响应 +0.09~+0.12）。

### 预注册判读（跑前冻结）

- **L1（解锁判定，主）**：解锁 = 该 run 的最终 Δc（vs
  s0 base）落在历史健康响应带内（λ=0.3: ≥ +0.05；
  λ=1.0: ≥ +0.05；λ=3.0: ≥ +0.05——历史带 0.069-0.126
  的下沿留余量）。
  - **≥1 剂量的 4 run 中 ≥3 解锁** → 锁定是**剂量特异**
    的：高剂量 forcing 可逃逸低 d 盆地——「分岔盆地的
    势垒随剂量降低」；
  - **全部剂量合计解锁 ≤2/12** → 锁定**接近绝对**：低 d
    盆地对 whiten 族干预深锁——几何干预不可逆性的最强
    形态，Amendment 5 机制段补一句「and the locked basin
    is not escaped by any higher dose」；
  - 其间 → 如实报告各剂量解锁率。
- **L2（几何响应）**：解锁 run 的 Δd 应同步恢复（≥ +20）；
  若 Δc 恢复而 Δd 仍矮 → 解耦异常，如实报告。
- **L3（功能保持）**：id_keep ≥ −0.02。
- **不做的**：不动归档；论文变更仅限 L1 两分支的既定措辞
  （上已写明），无其他触发。

### L1 判读：DOSE-SPECIFIC LOCK（剂量单调解锁）

- λ=0.3：0/4 解锁（Δc +0.031~+0.040——半恢复，未达标）；
- λ=1.0：2/4（seed7 源全解锁、seed13 源贴线未达）；
- λ=3.0：**4/4 全解锁**（Δc +0.054~+0.062）。

**锁定是剂量特异的**：低 d 盆地的势垒随 forcing 剂量降低，
λ=3.0 的持续 forcing 可把两个独立失灵源的表征全部拉回健康
响应带。解锁呈单调剂量梯度（0% → 50% → 100%），且**两个
失灵源的解锁阈值不同**（seed7 在 λ=1.0 即解锁、seed13 需
λ=3.0）——盆地深度本身也有分布。

### L2/L3

L2：解锁 run 的 Δd 全部同步恢复（65–111，无 Δc 恢复而
Δd 矮的解耦异常）。L3：12/12 id_keep ≥ +0.0074（全部
正偏，解锁过程无损 ID）。

### 合并机制终图景（M1a + M1b + P13）

1. **分岔**（M1a）：低剂量 forcing 下，前 40ep 内几何状态
   以 15–44% 概率分岔入低 d 盆地；标量 loss 无预警。
2. **锁定**（M1b）：分岔后对该剂量不可逆（4/4 vs 0/4，
   160ep 同剂量 forcing 翻不了盘）。
3. **可解**（P13）：锁定不是绝对的——更高剂量（1.0–3.0）
   可单调解锁；阈值因盆地而异。

**实践含义**：几何干预的「失败模式」不是不可逆损伤，而是
**局部吸引域**——干预剂量决定了从该域逃逸的能力。对剂量-
响应实验设计的直接推论：低剂量点的失灵（及由此的 b 远足）
可以用一次高剂量复位 + 重跑低剂量来补救——但补救后的
run 不再是独立抽样（已脱离原分岔链），ADR-0017 的抽样
设计结论不变。
