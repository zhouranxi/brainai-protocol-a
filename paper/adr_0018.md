# ADR-0018：λ=0.03 失灵表型的机制解剖——P12

- 状态：M1a 已发射（跑后待收）

- 前置：ADR-0017 P10（15% 远足率 + λ=0.03 失灵机制定位）与
  2026-11-14 零 GPU 探针（失灵 run 的 Δd 矮 30–50%、轨迹
  ep20–100 平台期、ID 健康）
- 决策人：Lance（用户）；执行：WorkBuddy（无涯智）

## 一、问题与已有证据

ADR-0017 判定：b 远足的充分机制是 λ=0.03 低剂量响应失灵
（15% 概率，same-seed 复刻不复现）。零 GPU 探针（2026-11-14
00:30，3 失灵 vs 9 健康，全部 λ=0.03）发现失灵 run 共享一个
连贯表型：

1. **Δd 矮 30–50%**：失灵 3.3/4.1 vs 健康 6.6–10.2——
   forcing 没把 d 推上去（推翻「d 上去 c 没跟上」的旧理解）；
2. **轨迹前半平台**：失灵 run 的 d_ent 在 ep20–100 卡在
   10–14，健康 run 一路 13→19；
3. **ID 健康**（test 0.877）、glue_r 无异样——故障局限在
   几何传导链。

**本 ADR 要回答的机制问题**：失灵在训练过程里何时发生、
由什么承载——(a) 早期锁定（ep<40 的权重状态决定整 run
命运）还是 (b) 后期分化（ep40 时失灵与健康还不可区分）？
失灵 run 的 forcing loss 分量是否从一开始就与健康分离
（「未咬合」假说）？

## 二、设计（跑前冻结）

### 仪表补丁（对 train_forcing_p4.py 的三处最小改动）

1. 最终 run JSON 的行加 `"history"` 字段（per-epoch 的
   train/test/forcing_loss，训练时已在 `hist` 内计算，只是
   此前未随 JSON 落盘）；
2. `ep==40` 时额外保存权重快照 `{tag}__{kind}_lam{lam}_ep40snap.pt`
   （不覆盖滚动 checkpoint；ep40 是探针平台上第一拐点前）；
3. `--resume-snap PATH` 参数：加载快照权重后按常规协议继续
   训练（optimizer/scheduler 重置，训练随机由 --seed 驱动）。
   默认路径（不带该参数）行为与历史协议逐字一致。

### M1a（收集批，16 run）

s0、s3 各 8 个 run-seed（7..14，避开已用的 0–6），λ=0.03，
200ep，协议与 P5–P11 逐字一致 + 仪表。GPU0/GPU2 各一条链
（s0 / s3），墙钟 ~8h。产出：16 份带完整 history 的 run +
每 run 的 ep40 快照。

### M1b（分叉批，8 run，条件触发）

**触发条件（冻结）**：M1a 收判时若新失灵 run ≥ 1 个。
从新失灵 run 的 ep40 快照分叉 4 个（--seed 101..104）；
同时从同批同种子的一个健康 run 的 ep40 快照分叉 4 个
（对照）。若 M1a 零失灵：M1b 不启动，P12 按 K1 的零失灵
分支收口。

## 三、预注册判读（跑前冻结）

### K1（M1a 主判读：失灵的时序定位）

- 记每 run 前 40ep 平均 forcing_loss（history 直接可算）
  与最终 Δd/Δc。失灵定义沿用 ADR-0017：|Δc| ≤ 0.022。
- **分层判读**：若失灵 run 的 fl@1-40 全部低于健康 run 的
  最小值（不重叠）→ **早期未咬合**：forcing loss 从头就没
  咬住，d 推不动，c 无响应——机制 (a) 的 loss 层证据；
- 若重叠 → 失灵在 ep40 后才分化（fl 早期不可分辨）→ 机制
  待 M1b 分叉判读；
- 同时报告新失灵率 k/16（更新 15% 的先验 CI）。

### J1（M1b 判读：失灵由什么承载）

- 失灵源分叉的 4 个 run 中 **≥2 个仍失灵**（|Δc|≤0.022）
  → **ep40 权重状态承载失灵**（早期锁定）；
- **0/4 失灵** → 失灵由 ep40 之后的随机性承载（后期分化），
  ep40 权重可自愈；
- 1/4 → 混合，如实报告。
- 健康源对照的失灵数并列报告（基线漂移检查；若健康源也
  出 ≥2 失灵则「锁定」判读降格为「分叉方差大」）。

### K2（功能保持）

16+8 run 的 id_keep ≥ −0.02。

### 不做的

- 不动 P5–P11 归档；不触发论文变更（机制结论先落 ADR，
