# ADR-0033：坍缩的分布干预批——改数据能否阻止坍缩吸引子成型

- 状态：已预注册，待服务器可用后发射
- 日期：2026-11-24 13:00 立项
- 动机：P24 证明改目标（CE+cons）救不了坍缩（0/3 翻转，范数收缩更深）。因果链还剩最后一环未测：**改训练分布**。若数据干预也失败，"此任务族下引导反馈无解、pre-gate 是唯一出路"彻底闭合；若成功，是全程序第一个建造性正结果（坍缩可预防 → 反馈可救）。

## 一、设计

### 三臂（全部 60ep，ResNet-18，CIFAR-10，遮挡 sev3 为"压力"）

| 臂 | 训练分布 | 逻辑 |
|---|---|---|
| `occ`（基线复现） | 纯遮挡 sev3 | 应复现 ρ<0（P23/P24 已三次观测） |
| `mix`（混合） | 每 batch 内 clean : occluded = 1 : 1（样本级交错） | 两分布同时在场，模型必须学习对两侧都保持误差可见的表征 |
| `curr`（课程） | 前 30ep 纯 clean → 后 30ep 纯 occluded sev3 | 先建正常误差几何，再适应压力；检验适应是否必然带走误差信号 |

- seeds {0,1,2}，共 9 runs；优化器/调度与 P24 完全一致（SGD 0.125 + cosine）
- 训练期数据增强同 P24（RandomCrop + Flip）；`mix` 臂的 clean 样本同样过增强
- 探针：P23 套件原样（fit_predictors 50ep 冻结头部 + sweep_errors sev 0–5），ρ 定义一致（occluded 测试集 sev1–5 误差 vs 严重度）

### 冻结判据

| 判据 | 闸门 | 含义 |
|---|---|---|
| **R-D1 预防成功** | `mix` 或 `curr` 在 ≥2/3 seeds 上 ρ ≥ 0，且 `occ` 臂保持 ρ < 0 | 坍缩可被数据干预阻止 → 开建造性路线（防坍缩训练配方 + PC-A0 重跑） |
| **R-D0 预防失败** | 两个干预臂均 < 0（或未达 2/3） | 分布干预与目标干预双双失败 → 因果链闭合为"此任务族下无解" |

边界情形（任一干预臂 ρ 在 [−0.2, 0) 且无翻转）：记"部分缓解"，不算成功；报告效应量。

### 次要读出（不设闸门）

1. **干净测试准确率**（三臂 sev=0）：预防的代价量化——若 mix/curr 干净精度暴跌 >5pp，即便 ρ 翻正也要报告 trade-off
2. **norm@s5/s0**：干预是否同时阻止范数收缩（几何层面的印证）
3. **curr 臂的分段时序**：30ep 边界前后 ρ 的走势（若预算允许在中点存 ckpt 加测一次，否则只测终点）
4. **mix 臂的 clean 子批 vs occluded 子批行为差**：混合是否产生"分配式"解（clean 通路正常、occluded 通路坍缩）

## 四、判读（2026-11-24 16:30 填，10/10 runs 完成）

数据：`runs/v2_p33/` 共 10 个 JSON（occ×3、mix×3、curr×3、clean×1），GPU0/GPU1 双卡并行，单 run 517–672s。curr 臂此前 ep30 崩溃（quick_rho 后梯度未恢复）已修复，三 seed 均完整穿过 30ep 相位切换点。JSON 已归档本地 `runs/p33/`。

### 4.1 主判据：逐 seed ρ（终点 ep60；occluded 测试 sev1–5 误差 vs 严重度）

| seed | occ（基线） | mix（混合） | curr（课程） | curr mid ρ（ep30） |
|---|---|---|---|---|
| s0 | −0.915 | −0.967 | −0.864 | −0.928 |
| s1 | −0.974 | −0.978 | −0.922 | −0.950 |
| s2 | −0.966 | −0.966 | −0.895 | −0.976 |
| 翻正 seed 数 | 0/3 | 0/3 | 0/3 | — |

- occ 基线复现 ✓：三 seed 全深负，与 P23/P24 的三次观测一致
- mix：0/3 翻正，全部深负（≤ −0.966），无一落入边界带 [−0.2, 0)
- curr：0/3 翻正（≤ −0.864），同样远离边界带

**判定：R-D0 预防失败（双败）。** 两个干预臂均不满足 R-D1，且连"部分缓解"都未触及。分布干预与目标干预（P24 CE+cons）双双失败 → **因果链闭合：此任务族下引导反馈无解，pre-gate 是唯一出路。**

机制侧写（为何 ρ 深负而非只是压平）：干预臂把误差–严重度曲线压出"训练严重度凹陷"——模型对 sev3（训练分布）过拟合，sev3 附近 acc 反超相邻严重度（occ_s0：acc@s3 0.781 > acc@s2 0.623；mix 三 seed 同型），探针平均误差随严重度不升反降（mix_s0：sev1→5 均值 0.168→0.135 单调递减）。数据干预没有恢复"误差随严重度增长"的健康几何，反而制造了反向几何。

### 4.2 次要读出

**干净精度代价（acc@s0 / acc@s5）**

| 臂 | acc@s0（3 seed） | acc@s5（3 seed） |
|---|---|---|
| occ | 0.752 / 0.754 / 0.742 | 0.199 / 0.229 / 0.175 |
| mix | 0.761 / 0.761 / 0.763 | 0.219 / 0.225 / 0.193 |
| curr | **0.106 / 0.100 / 0.100（≈随机）** | 0.100（≈随机） |
| clean（校准） | 0.853 | 0.160 |

- mix 无干净精度代价（与 occ 差 <2pp，远低于 5pp 阈值）——但 ρ 未翻正，属"无代价的无效干预"
- curr 灾难性遗忘：前 30ep 纯 clean 建立的干净精度（ep20 实测 0.674）在后 30ep 纯遮挡训练中被完全抹除，ep40 0.546 → ep60 0.100（chance level）。课程干预双重失败：ρ 未救回 + 干净能力归零

**norm@s5/s0（范数几何）**

| 臂 | norm@s5/s0（3 seed） | 解读 |
|---|---|---|
| occ | 0.31 / 2.61 / 0.05 | seed 间异质，无一致形态 |
| mix | **1.01 / 1.04 / 1.02** | 范数–严重度曲线完全压平 |
| curr | 0.00 / 0.00 / 0.00 | 重遮挡下特征范数湮灭 |
| clean | 0.48 | 温和收缩（常态） |

- **范数签名与 ρ 签名可分离**：mix 彻底抹平了范数收缩（s5/s0 ≈ 1.0）却完全没救回 ρ（−0.97）。这反向加强主主张：范数收缩是伴随现象，误差可见性（ρ）才是坍缩的深层标记
- curr 是全面湮灭：norm@s0 本身已缩至 0.003–0.145，s5 处归零

### 4.3 clean 校准臂讨论（ep30 mid-ρ 基线）

- clean_s0：ep30 mid ρ = **+0.956**，ep60 终点 +0.984；干净 acc 正常增长（ep20 0.787 → ep60 0.948）
- 即：纯 clean 训练到第 30ep 时，occluded 测试上的误差–严重度关系已呈**强健康签名**（误差随严重度单调上升）。"中期收缩"不是训练动力学的常态副产品——预注册的两个备选解释（clean mid 也强负 → 常态；温和 → 待讨论）都不成立，实际结果更强：同期 clean 基线是强正的

curr 臂同期 mid ρ = −0.928 / −0.950 / −0.976（3/3 深负），与 clean 校准**符号相反**。两者按设计前 30ep 应为同一训练（纯 clean、同超参），出现系统性分歧。两点写入讨论（均不影响 R-D0 判定——终点探针十臂同码同法，主判据无混杂）：

1. curr 臂 phase-1 与 clean 臂并非逐位等价：ep20 干净测试 acc 已分歧（curr 0.674 vs clean 0.787），推测课程调度实例化了额外数据管线、RNG/加载路径不同，mid-ρ 的臂间对比只能作定性参考
2. clean 校准 n=1（单 seed）；若要支撑"curr 早期即偏离健康几何"的强结论，需补 clean seed 1/2 校准（~10min/run，可并入后续批次）
