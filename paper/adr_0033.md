# ADR-0033：坍缩的分布干预批——改数据能否阻止坍缩吸引子成型

- 状态：已预注册，待服务器可用后发射
- 日期：2026-11-24 13:00 立项
- 动机：P24 证明改目标（CE+cons）救不了坍缩（0/3 翻转，范数收缩更深）。因果链还剩最后一环未测：**改训练分布**。若数据干预也失败，"此任务族下引导反馈无解、pre-gate 是唯一出路"彻底闭合；若成功，是全程序第一个建造性正结果（坍缩可预防 → 反馈可救）。

## 一、设计

### 三臂（全部 60ep，ResNet-18，CIFAR-10，遮挡 sev3 为"压力"）

| 臂 | 训练分布 | 逻辑 |
|---|---|---|
| `occ`（基线复现） | 纯遮挡 sev3 | 应复现 ρ<0（P23/P24 已三次观测） |
| `mix`（混合） | 每 batch 内 clean : occluded = 1 : 1（样本级交错） | 两分布同时在场，模型必须学习对两侧都保持误差可见的表征 |
| `curr`（课程） | 前 30ep 纯 clean → 后 30ep 纯 occluded sev3 | 先建正常误差几何，再适应压力；检验适应是否必然带走误差信号 |

- seeds {0,1,2}，共 9 runs；优化器/调度与 P24 完全一致（SGD 0.125 + cosine）
- 训练期数据增强同 P24（RandomCrop + Flip）；`mix` 臂的 clean 样本同样过增强
- 探针：P23 套件原样（fit_predictors 50ep 冻结头部 + sweep_errors sev 0–5），ρ 定义一致（occluded 测试集 sev1–5 误差 vs 严重度）

### 冻结判据

| 判据 | 闸门 | 含义 |
|---|---|---|
| **R-D1 预防成功** | `mix` 或 `curr` 在 ≥2/3 seeds 上 ρ ≥ 0，且 `occ` 臂保持 ρ < 0 | 坍缩可被数据干预阻止 → 开建造性路线（防坍缩训练配方 + PC-A0 重跑） |
| **R-D0 预防失败** | 两个干预臂均 < 0（或未达 2/3） | 分布干预与目标干预双双失败 → 因果链闭合为"此任务族下无解" |

边界情形（任一干预臂 ρ 在 [−0.2, 0) 且无翻转）：记"部分缓解"，不算成功；报告效应量。

### 次要读出（不设闸门）

1. **干净测试准确率**（三臂 sev=0）：预防的代价量化——若 mix/curr 干净精度暴跌 >5pp，即便 ρ 翻正也要报告 trade-off
2. **norm@s5/s0**：干预是否同时阻止范数收缩（几何层面的印证）
3. **curr 臂的分段时序**：30ep 边界前后 ρ 的走势（若预算允许在中点存 ckpt 加测一次，否则只测终点）
4. **mix 臂的 clean 子批 vs occluded 子批行为差**：混合是否产生"分配式"解（clean 通路正常、occluded 通路坍缩）
