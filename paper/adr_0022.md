# ADR-0022：层级反馈增益的瓶颈测试架——P16/P17

- 状态：已收口（G2 全零闸：无增益是瓶颈不变的——任务冗余假设否决；P17 不触发，转 P18 LLM 侧）
- 日期：2026-11-17 00:27 立项
- 前置：ADR-0019/0020（top-down 反馈在易任务上零增益）
  与 2026-11-17 00:23 研究计划（用户确认立项）
- 决策人：Lance（用户）；执行：WorkBuddy（无涯智）

## 一、问题与根因假设

ADR-0019 判定：FF/REC/HFB 三配置在 CIFAR-10（FF≈0.95）
上 ID 无差、调制塌零、缩放梯度为零。根因假设：**任务
冗余**——前馈通路已足以解决任务，反馈通路没有存在必要，
故学不到任何东西。文献中 top-down 增益真实出现的条件是
前馈不足（遮挡/退化输入/容量受限/数据稀缺）。

**P16 检验**：制造前馈瓶颈，看层级反馈是否获得增益窗口。

## 二、P16 设计（跑前冻结）

### 瓶颈 × 配置矩阵

| 瓶颈 | 操作 | run |
|---|---|---|
| B1 输入退化 | 结构化遮挡：8×8 块状掩码，25% 可见（训练+测试） | 3 配置 × 3 种子 = 9 |
| B2 容量受限 | stem/首层 64→16 通道（全局宽度 ×0.5） | 9 |
| B3 数据稀缺 | 10% 训练数据（5k 张），100ep | 9 |

- 配置沿用 models_hierarchy.py（FF/REC/HFB，纯调制残差
  版）；协议沿用 N1″（wd 2e-3、RandAugment、早停最佳点、
  100ep）。B1 的 RandAugment 关闭（掩码本身即退化）。
- B3 的早停以 10% 的 held-out val 为准（防测试泄漏）。
- 测量：ID test + 交换读数（off）+ c100 探针 + **c10c**
  （三口径，ADR-0021 规范）。
- 资源：27 run，GPU0/GPU2 双链（~9h 一卡串行 → 双卡
  ~4.5h + 探针/腐蚀评估）。

### 判读（冻结）

- **G1（Go 闸）**：任一瓶颈下 HFB−FF ≥ +1pp 且三种子
  同号 → **增益窗口存在**，P17 启动（该瓶颈为载体）；
- **G2（全零闸）**：三瓶颈全部 |HFB−FF| < 1pp 或符号
  不一致 → 「该任务族反馈无增益」升级为**瓶颈不变**结论，
  架构侧收线，转 P18（LLM 侧）；
- **G3（REC 对照）**：若 REC 也增益且 ≈HFB → 增益来自
  迭代预算而非层级（「层级先验」叙事再受挫）；若 HFB >
  REC +1pp → 层级特异性在瓶颈下出现。
- **G4（健康闸）**：各瓶颈内 FF 的 id ≥ 0.60（任务可学
  但未饱和——保证瓶颈「难而不废」；低于则该瓶颈作废并
  记录）。
- 三口径报告全部 run；探针增益不单独作为任何判读依据
  （ADR-0021 教训入规）。

## 三、P17 预注册（条件触发：G1 通过）

在 Go 瓶颈上重跑「重塑 vs 引导」裁决：

- swap 读数（原配 vs off）→ r/q 分解（G≈0 保护分支沿用）；

  开>关 → 推理时引导为真；

### G2 全零闸触发：任务冗余假设否决

三个瓶颈（FF 分别 0.75/0.93/0.83——全部「难而不废」，
G4 全过，瓶颈设计有效）下 HFB−FF 全部在 ±0.5pp 噪声带内、
符号不一致。**「反馈无增益」升级为瓶颈不变的结论**：不是
任务太易导致反馈冗余——该实现族的 top-down 调制在输入
退化、容量受限、数据稀缺三种前馈不足场景下同样不产生
任何 ID 增益。

结合 ADR-0019（易任务零增益 + 缩放扫描否决），证据链
完整：**纯调制式 top-down 反馈（轻量残差型）在小视觉
架构上无增益，且该结论对任务难度不敏感**。可能的残余
解释（记录，不立项）：增益需要更强的反馈形式（非残差
调制的重权写回）或与训练目标耦合（predictive coding 的
自监督损失），而非任何形式的信息通路本身。

### G3 附带

data 瓶颈下 HFB−REC +1.2pp（弱层级特异）；mask/width
迭代仅预算差。均未过 +1pp 门槛。

### 旁观察（不判读）

REC 的 c100 探针读数在全部三个瓶颈下再次显著高于
FF/HFB（0.35-0.38 vs 0.23-0.28）——ADR-0020 的探针可读性
效应在瓶颈场景下完全复现。仅记录。
